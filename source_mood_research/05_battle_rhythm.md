# 05. 전투의 리듬

[README](README.md)로 돌아가기.

한 스테이지가 어떤 감정 순서로 흐르는지, 시스템창이 서사에 어떻게 끼어드는지, 규모감과 승리·손실의 무게, 전투 사이의 쉼을 정리한다. [Vnn]은 [99_sources.md](99_sources.md) 2장 검증 표의 번호다. «(N화 직접 봄)»은 공식 영어판 웹툰 관찰이다.

**매체 주의.** 나무위키의 창 문구와 결산 기록은 **소설** 기준이다. 웹툰이 같은 문구·양식을 쓰는지는 일부만 확인했다(3.5절). 이 장의 개별 전투 장면은 «그 스테이지 하나의 기록»이다. 이전 조사에서 기각된 일반화(«병력은 시간, 영웅은 결정타» 등, R1-X1~X6)로 넓히지 않는다.

## 1. 한 스테이지의 감정 곡선

### 1.1 소설: 부제로 본 곡선

나무위키 에피소드 목록의 스테이지 부제(소설) [V19].

| 스테이지 | 부제 순서 | 곡선 읽기(해석) |
|---|---|---|
| 0 | 튜토리얼이 시작합니다 → 하늘이 무너져도 → 솟아날 구멍은 있다 → 결전 → 튜토리얼의 끝 | 절망 → 실마리 → 결전 → 끝 |
| 1 | 전쟁 준비 → 괴물들이 온다 → 킬존 → 용병의 생존수칙 → 메인 파티 → 보스 레이드 | 준비 → 출현 → 함정 지대 → 버티기 → 주력 → 보스 |
| 2 | 물량 앞에 장사 없다 → 무너진 성벽 → 이해할 수 없는 일 → 무게 | 물량 → 붕괴 → 이변 → 대가 |
| 5 | 시산혈해 → … → N등급 → … → 사형이다! → 155명 | 참혹 → 약자의 차례 → 결정타 → 처단 → 숫자 |
| 9 | 요르문간도 → 왜 거기서 나와 → 난입 → … → 노 옵션 → 시위를 떠난 화살 | 거대 보스 → 뜻밖의 등장 → 선택지 없음 → 돌이킬 수 없는 결정 |

- 아크의 마지막 부제 10개 가운데 넷(«튜토리얼의 끝», «무게», «155명», «시위를 떠난 화살»)이 대가나 여파를 이름 붙인다 [V19]. «155명»이 사망자 수인지는 확인하지 못했다 [V24].
- (해석) «준비 → 출현 → 물량·이변 압박 → 붕괴나 딜레마 → 결정타 → 정산». 승리 순간이 아니라 정산에서 막을 내리는 스테이지가 눈에 띈다.

## 2. 열림: 숫자와 카운트다운

- 소설은 대괄호 창 «[적 정보 - STAGE n]»으로 스테이지를 연다. 마릿수·레벨이 줄마다 적히고, 일부 스테이지는 «시작까지 : 10분»(STAGE 2), «9일»(STAGE 5), «10일»(STAGE 7·9)이 붙는다 [V14].
- 목표·보상은 그 앞 창에 있다(STAGE 0 «괴수의 습격에서 생존하라», 보상 «???») [V14].
- 시작 창 앞에 다크 이벤트 창(«[발동한 다크 이벤트 : …]» 또는 «발동하지 않습니다») 이 먼저 오는 스테이지가 많다 [V14].
- STAGE 0 적은 여왕 1(Lv.??), 공성병 196(Lv.60), 돌격병 912(Lv.55)로 모두 1,109다. 결산의 아군 레벨은 애쉬 Lv.5, 데미안 Lv.15, 루카스 Lv.27이다 [V14][V22].
- (해석) 절망이 서술보다 먼저 **숫자 격차**로 온다. 창이 건조해서 공포가 커진다.
- 웹툰: 2화에서 주인공이 시스템창을 부르자 SWISH와 함께 여러 장이 떠오른다(적 정보, 유물 «고대 마나 대포(SR)») (2화 직접 봄). 13화는 정비 화의 마지막 컷을 검은 바탕 청록 창 «[STAGE 1] 2 days and 13 hours remaining»과 TICK으로 닫는다(13화 직접 봄).

## 3. 시스템창이 서사에 끼어드는 방식

### 3.1 소설 결산창: 축하와 죽음이 한 목록에

STAGE 0 결산 순서 [V15]:
1. «[STAGE 0 - CLEAR!]»
2. «[STAGE MVP - 데미안(N)]»
3. «[레벨업 캐릭터]» — 이름(등급) Lv.n (↑m), 애쉬 줄 끝에 «(직업 선택이 가능합니다!)»
4. «[사망 및 부상 캐릭터]» — «켄(N) : 사망», «릴리(R) : 중상»
5. «[획득 아이템]»
6. 보상 지급 안내

- (해석) 축하(CLEAR!, MVP, ↑, 느낌표)와 죽음이 같은 서식, 같은 목록에 놓인다. 사망 줄이 레벨업과 전리품 사이에 끼어 있다. 시스템이 사람의 죽음을 마석 개수와 같은 무게로 정산하는 냉담함이 섬뜩함을 만든다.
- 이름 없는 병사는 사망 목록에 없다. STAGE 0은 생존자 9명뿐인데 사망 줄은 켄 하나다 [V15].

### 3.2 사상자가 커지면 이름이 접힌다

- 초반은 이름 하나하나다(STAGE 1 테인·론·지야·페케(N)) [V15].
- 대규모전은 «마르헤리타(R) 외 20인»(STAGE 15), «스쿨드(SSR), 켈리손(SR), 번아웃(SR), 그 외 52인»(STAGE 35), «더스크 브링어(SSR), 노바디(SR), 그 외 188인»(STAGE 40)처럼 접히고 «<목록 펼치기>»가 붙는다 [V15]. STAGE 15에는 «[실종 캐릭터]»가 따로 있다 [V15].
- (해석) 전쟁이 커질수록 이름이 «외 N인»에 삼켜지는 감각을 **UI 서식 자체**가 만든다.

### 3.3 문구의 톤

- 정중한 안내체: «이 이상 난이도를 올릴 수 없습니다», «<승급 퀘스트를 진행하여 주십시오.>» [V17].
- 게임 퀘스트체: «[기습해 온 웨어울프 군단을 물리쳐라!!]», «※ '난입 페널티'가 적용됩니다.» [V17].
- 가림: «보상 : ???», «Lv.??», «데미안(??)» [V17].
- 정체 모를 개입: STAGE 11~14 시작 창에 «[???의 ??가 턴을 넘깁니다.]» [V17].
- 마지막 스테이지 직전 안내는 최종전 준비를 권한 뒤 «플레이어»에게 행운을 빈다 [V17].
- (해석) 시스템 목소리는 감정 없이 정중하고 게임답게 경쾌하다. 그 경쾌함이 참상과 어긋나 냉소가 생긴다. 끝까지 주인공을 «플레이어»라 부르는 것과 «???»는 이 세계가 누군가에겐 게임판이라는 불길함을 남긴다.

### 3.4 등급 괄호

- 시스템창 안의 모든 이름 뒤에 등급 괄호가 붙는다. 설정 문서는 등급을 «SSR-SR-R-N으로 분류되는, 인간의 가치»라 소개하고, EX를 그 바깥의 규격외로 둔다 [V16].
- 낮은 등급 MVP: STAGE 0·7 데미안(N), STAGE 4 릴리(R), STAGE 25 애쉬(EX)와 스칼렛(N) 공동 [V16].
- (해석) 등급은 사람에게 붙인 가격표다. N이 MVP에 찍히면 시스템의 평가가 뒤집히는 쾌감이 생기고, 같은 괄호가 사망 줄에도 붙어 죽은 사람도 끝까지 등급으로 불린다.

### 3.5 웹툰은 결산을 어떻게 그렸나

- 웹툰에서 본 클리어 화면은 «CLEARED» + 보상 안내 + 파란 보물상자 아이콘이다. 20화는 «STAGE MVP! ★★★» + 도트 쥬피터 + «Jupiter (SR)»를 덧붙인다(8·20화 직접 봄).
- 사망자는 결산 목록이 아니라 **전투 중 별도 패널**로 나왔다. 피 튄 검붉은 배경 위 회색 도트 넷과 «RON (N) / PEQUE (N) / JIYA (N) / TEIN (N)»이다(18화 직접 봄). 이름이 소설 STAGE 1 사망자와 같다 [V23].
- 8화는 결산 전에 «수백 명 중 아홉»이라는 큰 글자 내레이션, 흰 천의 시신 줄, 장례를 먼저 보여 준다(8화 직접 봄).
- 9·19화를 보지 않아서 웹툰에 소설식 사망 결산 목록이 따로 있는지는 확인하지 못했다.
- (해석) 기쁨과 숫자의 순서는 잃은 것의 크기에 따라 갈린다.
  - 크게 잃은 STAGE 0(7→8화): 7화는 결정타의 흰 섬광으로 끝나고 햇살·함성·결산이 없다. 8화가 숫자·장례를 먼저 보이고 «STAGE 0 CLEARED!»는 맨 끝에 띄운다. **대가 먼저, 결산 나중**이다.
  - 큰 손실 없이 막은 STAGE 1(20→21화): 햇살 → 함성 → 검은 화면 → CLEARED → MVP. **기쁨 먼저**이고, 이름 있는 넷의 죽음은 다음 화 연회 속 자책으로 돌아온다.
  - 두 스테이지뿐이라 규칙이라기보다 선례 둘이다. 어느 쪽이든 손실은 결산 목록보다 장면(이름표, 장례, 휠체어)으로 남긴다.

### 3.6 웹툰의 창 색 규칙

금 = 지휘관 스킬, 청·시안 = 정보·클리어·카운트다운, 붉은 글리치 = 페널티·경고, 피 튄 붉은 바탕의 회색 도트 = 사망(7·13·18·20화 직접 봄). 상세는 [04 §6](04_webtoon_visuals.md#6-시스템창과-알림창).

## 5. 규모감

- 적 물량(소설): STAGE 0 약 1,100, STAGE 1 리빙아머 1,052, STAGE 2 거대 시궁쥐 3,251, STAGE 15 고블린 22,940(다크 이벤트 «번식»으로 45,880, 문서 계산 총 48,390). STAGE 9는 정보창에 «Lv.? ??? : 1체»뿐이고 각주가 요르문간드라 밝힌다 [V14].
- (해석) «거대한 것 하나»부터 «수만 마리»까지 스테이지마다 위협의 모양이 바뀐다.
- 지휘관 시점: [지도 작성]은 전장 전체를 «도트 형태의 미니맵»으로 본다 [V18].
- 웹툰의 세 겹(직접 봄):
  - 전체: 지평선까지 깔린 검은 덩어리와 붉은 눈 점(1·3화), 불길 너머 빽빽한 갑옷 떼(18화).
  - 지휘: 요새 부감 배치도(3화), 적 현황창의 숫자(18화).
  - 한 사람: 포신을 멘 손의 화상, 피눈물(7화), 이름표(18화).
- 크기 대비: 20화 보스는 성벽 높이이고, 대검이 성벽에 박혀 남는다. 20화 베스트 댓글 1~3위가 모두 규모(«큰 칼», «성벽에 박힌 대검», «보스가 성벽만큼 클 줄 몰랐다»)에 반응했다(20화 직접 봄).
- 아군 규모도 자란다: 8화 생존자 9명 → 13화 병력 526명 → 18화 성벽을 메운 붉은 튜닉 군상(직접 봄).

## 6. 승리의 무게

- **결정타 직전의 희생**(7화 직접 봄): 불꽃 몸의 릴리가 피를 흘리며 입구를 막고, 애쉬가 화상을 감수하며 포신을 메고, 병사들이 같이 받치고, 피눈물의 데미안이 쏜다. 화면 전체가 시안으로 빛나고, 검은 화면 내레이션 뒤에 보이지 않던 여왕 이마에 맞는다.
- **결정타와 상실이 한 장면에**(소설 STAGE 5): 쥬니어의 궁극기 [원소 해체]가 셀렌디온의 혈마법과 육체강화를 봉인해 승리하는 그 장면에서, 쥬피터가 혈탄을 막다 쥬니어 품에서 숨진다 [V24].
- **승리 시퀀스**(20화 직접 봄): 먹구름 사이 햇살 → 장미 문장 깃발 → 치켜든 주먹과 «이겼다, 살아남았다» → 햇살 비친 성벽 부감 → 공포가 기쁨으로 바뀌는 병사 얼굴 → 성문 위 HURRAH → 검은 바탕 결산창 → MVP.
- 7화 베스트 댓글은 «난이도 설정을 동기부여 연설로 바꿨다»(2,491), «프롤로그인데 벌써 운다»(1,488)였다(7화 직접 봄).

## 8. 전투 사이 숨 고르기

### 8.1 비중

- 나무위키 에피소드 목록의 STAGE 0~9 구간에서 스테이지 부제는 46개(셈법에 따라 47), 비전투 부제(Side Story 약 76, 자유탐사 23, Evil Side 2, Auto Play 1)는 100개 남짓이다. 부제 기준으로 방어전은 **약 3할**이다 [V19].
- 부제 수와 화수는 다르다. 목록의 화수 표기가 엉망이라 화수 기준 비율은 모른다 [V19].

### 8.2 반복되는 의례

- 반복이 확인된 부제는 «상자깡» 5회, «승리 연회» 2회, «장례식» 2회, «전쟁 준비»(스테이지 부제 1 + Side 3), «작전 지시» 2회다 [V19].
- «야식 시간», «도시경영게임», «100연뽑 하면 SR 확정권 주나요?»는 각 1회뿐이다 [V19].
- (해석) 전투 뒤는 «연회 → 상자깡 → 장례», 전투 앞은 «전쟁 준비 → 작전 지시»가 의례처럼 돌아온다. 결산의 보상 상자가 다음 화의 «상자깡» 개그로 이어진다.

### 8.3 웹툰의 순환 (13·21화 직접 봄)

- 21화: 보름달 아래 광장 연회(긴 식탁, 등불, 음표 오버레이) → 홀로 앉은 애쉬의 자책(검은 바탕 + 붉은 질감 패널) → 루카스의 위로(«웃는 것도 지휘관의 의무») → 개그 몰림(채소만 먹는 애쉬에 오열하는 주민, 취해 은퇴를 조르는 릴리, 취한 데미안의 고백) → 파티 시너지 도표 → 건배(쓰러진 전우, 살아남은 우리, 전하) → 숙소의 보상 상자 셋(R·N 등급 이름표, SSR 장갑에 금빛 섬광).
- 13화: 병력 보고 → 용병 모집·황궁 지원(붉은 WARNING을 무릅씀)·길드 징발 → 직업 선택(축하창 → 붉은 디버프창) → 길드 협상 → 카운트다운.
- (해석) 한 스테이지는 «결전 → 대가 → 정비·경영 → 다음 결전 → 승리 → 연회 → 상자 → 카운트다운»으로 한 바퀴 돈다. 정서의 높낮이가 이 순서를 따른다.
- 13화의 «축하창 바로 뒤 붉은 디버프창»은 «좋은 선택에도 대가가 있다»를 UI 한 번으로 준다(해석).

### 8.4 쉼에도 안전지대는 없다

- 캔들러는 가을 축제 날 병문안 온 동료들 곁에서 숨진다 [V28].
- 사령관 회담은 전투 한가운데의 강제 쉼표다. 고블린 신왕은 회담에서 시를 청하고 애쉬의 시에 운다. 이어지는 결투와 자결의 무게가 그만큼 커진다 [V26].
- 미궁 탐사는 어둠에 잠긴 «호수왕국» 도시 구역을 걷는다 [V12]. (해석) 지상의 수성전이 오늘의 생존이라면, 미궁은 이미 망한 나라를 걷는 정서다.
