> **먼저 읽을 것 — 본 범위와 못 본 것**
> - 한국어 원본(네이버 웹툰)은 **보지 못했다.** 브라우저 확장의 안전 정책과 WebFetch가 모두 comic.naver.com을 막았다. 대신 같은 원고의 공식 영어판 WEBTOON(title_no=10765)을 봤다.
> - 영어판 웹 무료분은 1~22화뿐이다. 그 가운데 **1·2·3·7·8·13·18·20·21화(9개 화)를 처음부터 끝까지** 봤고, 22화는 베스트 댓글만 읽었다.
> - 그래서 여기 관찰은 모두 작품 전체의 **초반**(STAGE 0~1, 소설 1년차 앞부분)이다. 진짜 중·후반(STAGE 5 이후, 2부)의 그림·연출은 보지 못했다.
> - 영어판은 번역·식자가 현지화돼 있다. 효과음 글자 모양과 대사 뉘앙스는 한국어판과 다를 수 있다. 그림·채색·컷 배치는 같은 원고로 본다(해석).
> - 웹툰 이미지는 저장하지 않았고 이 문서에도 넣지 않는다.

관찰마다 «(N화 직접 봄)»을 단다. «(해석)»은 관찰에서 미룬 판단이다.

## 2. 색

### 2.1 바탕과 강조색

- **바탕은 채도 낮은 회갈·청회**다. 낮·실내는 회갈, 밤은 남보라·청보라 단색, 회상은 세피아에 필름 노이즈다(1·2·3화 직접 봄). 무료분 뒤쪽에서도 성벽·하늘 바탕은 계속 채도 낮은 회청·회갈이다(18·20화 직접 봄).
- **강조색이 역할을 나눈다.**

| 누구 | 강조색 | 표시 |
|---|---|---|
| STAGE 0 적(검은 거미) | 형광 녹색 체액·점액·알주머니 + 붉은 홑눈 | 1·3·7화 직접 봄 |
| STAGE 1 적(리빙 아머·레이스 나이트) | 검은 갑옷 + 시안 유령불 | 13·18·20화 직접 봄 |
| 아군 | 진홍 피, 병사의 붉은 튜닉, 붉은 깃발, 애쉬의 붉은 안감 망토 | 1~21화 직접 봄 |
| 게임·마법 | 시안·하늘색(시스템창, 마나 대포 코어, 지도 작성 때 눈빛) | 2·3·7화 직접 봄 |
| 지휘관 스킬 | 금색(스킬창, 금빛 기둥·돔, 결단 때 눈빛) | 7·18·20화 직접 봄 |
| 경고·페널티 | 붉은 글리치·붉은 줄무늬 | 13화 직접 봄 |

- 적의 강조색은 **스테이지마다 바뀌고**, 바탕과 아군 색은 고정이다(7·18·20화 직접 봄).
- 1화에서 현실(스트리머 방) 구간은 컷 사이 여백이 검정이고, 게임 속 세계로 넘어간 뒤 흰색으로 바뀐다(1화 직접 봄).
- 썸네일 1~22화는 모두 인물 얼굴 클로즈업이다. 채도 낮은 바탕에 표정(이 악묾, 울먹임, 피 묻음)을 강조한다. 피 묻은 얼굴은 6·7·18화다(목록 직접 봄).

## 3. 선·채색·컷

- 굵기가 일정한 깔끔한 검정 외곽선, 2~3단 셀 채색, 하이라이트는 단단하게 끊는다. 배경에 종이·노이즈 질감을 자주 얹는다(1·2화 직접 봄).
- 감정 기호: 공포는 얼굴 위 **세로 해칭**, 분노·충격은 **방사형 집중선**, 속도는 **사선 속도선**, 회상은 **세피아 + 필름 노이즈**(1~3화 직접 봄).
- 결전 컷은 굵은 세로 속도선과 강한 대비, 발광 효과가 초반보다 세다(7·20화 직접 봄). 22화 범위에서 그림체 자체의 큰 변화는 없다(직접 봄).
- **여백으로 속도를 조절한다.** 대사 사이에 화면 높이만 한 빈 여백을 자주 둬 한 줄씩 끊어 읽히고, 결정적 대사 뒤에 정적이 생긴다(3화 직접 봄). 결정타 직전에는 검은 화면과 흰 상자 내레이션을 길게 이어 템포를 늦춘 뒤, 세로로 긴 컷 하나로 터뜨린다(7화 직접 봄).
- 말풍선: 내레이션은 굵은 검정 테 흰 직사각형, 속마음은 가시 털 테두리 원형, 외침은 물결 테, 폭군 위협은 검은 말풍선에 붉은 글자(2·3화 직접 봄).
- 컷 배치: 4인 반응은 계단식 세로 좁은 컷, 결의는 사선 눈 클로즈업 4연속, 사방이 붉은 눈인 원형 비네팅(2·3화 직접 봄). 파편과 효과음이 컷 밖 여백으로 튀어나간다(2·20화 직접 봄).
- 음악 연출: 21화 연회는 금빛 오선지와 음표가 컷 사이를 흐른다. 크레딧에 «Music: MZ - Victory Feast»가 적혀 있다(21화 직접 봄).

## 5. 몬스터 디자인

- **검은 거미**: 검은 키틴, 붉은 홑눈 6~8개, 녹색 점액이 흐르는 송곳니, 마디진 긴 다리. 한 마리가 사람보다 크다. 피 대신 녹색 체액이 튄다(1화 직접 봄).
- **떼**: 지평선까지 깔린 검은 덩어리에 무수한 붉은 점(눈). 산비탈을 미끄러져 내려오는 사선 속도선, 클로즈업에서는 다리가 비처럼 쏟아지는 세로 구도(1·3화 직접 봄).
- **거미 여왕**: 녹색으로 빛나는 거대한 알주머니 위에 흰 뿔 왕관을 쓴 검은 인간형 상체와 붉은 홑눈. 연기 속 실루엣과 녹색 발광으로 보스 크기를 낸다(3·7화 직접 봄).
- **리빙 아머**: 사람 크기의 속 빈 검은 판금, 눈·관절에서 시안 유령불. 위에서 보면 회청 금속 질감의 빽빽한 덩어리, 밤 숲길에서는 줄지은 푸른 불 점(13·18화 직접 봄).
- **레이스 나이트(STAGE 1 보스)**: 성벽 높이의 검은 판금, 시안 유령불 갈기, 거대한 대검. 등장 컷은 붉은 단색 필터에 십자 섬광 눈. 약점은 흉갑 속 푸른 구체 핵(20화 직접 봄).
- 도트 회상 속 다른 괴물: 회색 오우거 2, 녹색 눈 고블린 떼(2화 직접 봄).

## 6. 시스템창과 알림창

### 6.1 생김새

- **기본 시스템창**: 반투명 하늘색~청색 그라데이션, 모서리를 깎은 팔각형 판, 밝은 시안 테두리, 위쪽 얇은 띠와 **점 세 개**, 흰 산세리프 글꼴, 왼쪽에 진청 단색 실루엣 아이콘. 뒤 배경이 비친다(2화 직접 봄).
- **특성창**: 같은 팔각형이지만 특성마다 색이 다르다(릴리 «Flame Skin» 진홍, 켄 «Petty Thief's Survival Skills» 녹색). «DING»과 함께 원형 도트 아이콘, 큰 제목, 3줄 설명(유래 → 효과 → 비용)으로 뜬다(3화 직접 봄).
- **클리어창**: 검은 바탕에 진청 그라데이션, 가는 가로 스캔라인, 깎은 모서리, 위쪽 폴더 탭 모양 턱과 점 셋, 시안 테두리, 파란 보물상자 아이콘(8·20화 직접 봄).

| 파티 시너지 도표 | 13·21 | 어두운 판, 금색 회로선, 도트 초상 + 이름(등급) + Lv | 버프 원리를 설명할 때 |
| 보상 상자 | 21 | 실물 나무 상자 + 남색 이름표 «R-Rank Chest», 밑에서 푸른 빛. SSR은 금빛 섬광 | 연회가 끝난 밤 |

- (해석) **색이 의미를 나눈다.** 금 = 지휘관(플레이어)의 개입, 청·시안 = 시스템의 객관 정보, 빨강 = 대가·경고, 회색 도트 + 붉은 바탕 = 잃은 것.
- 시스템창은 주인공이 부르는 «도구»로 처음 나오고(2화), 인물의 과거를 증명하는 «극적 장치»(3화), 결단의 «보상»(7화)으로 쓰임이 넓어진다. 18화의 손실은 시스템창이 아니라 **시스템창 밖의 서사 패널**(피 튄 붉은 바탕의 이름표)로 알린다. 8·20화 클리어창에도 사망은 없다(직접 봄, 9·19화는 못 봄).

### 6.3 도트 스프라이트 = 게임 층

원작은 «게임으로서의 세계»를 그릴 때 일관되게 도트 스프라이트를 쓴다(직접 봄).
- 1화: 도트 결과창(남색 반투명 상자, 흰 도트 글꼴, «LAST STAGE CLEAR!»), 시체 위에 홀로 선 도트 루카스.
- 2화: 위에서 비스듬히 내려다본 도트 성벽(성벽 위 루카스, 성벽 앞 오우거·고블린 떼, 아래 붉은 창병 줄). 원작 속 «게임 화면»의 모습이다. 난이도 엠블럼(Hell = 뿔 달린 붉은 악마 해골, Ironman = 교차한 검과 투구 방패).
- 8·13화: 리셋하며 죽이던 도트 병사(스포트라이트 아래).
- 13화: 규칙 설명(도끼 아이콘에 붉은 X가 붙은 리빙 아머 = 물리 내성, 애쉬 스프라이트에서 병사 스프라이트로 퍼지는 푸른 오라 = 전군 버프).
- 18화: 전사자 이름표. 20화: MVP. 21화: 파티 시너지 도표.

(해석) 2D 도트 게임으로 옮길 때 가장 쉬운 연결고리다. 우리 게임은 화면 전체가 이미 도트라서, 원작의 «게임 층» 문법을 결산·추모 화면에 그대로 쓸 수 있다([08](08_for_our_game.md)). 단 창 디자인 자체(팔각형, 점 셋, 폴더 탭 턱)는 베끼지 않는다.

## 7. 효과음 글자

- 흰 외곽선의 굵은 붓 손글씨다. 색이 장면 성격을 따라간다(영어판 식자, 2·3·7·20화 직접 봄).
  - 폭발·피: 적갈~흑적 그라데이션(BAM, STAB, KILL!!, FIRE!!)
  - 위압·충격: 남보라·흑보라(DOOM, DADUN, BARROOM)
  - 마법: 파랑(VWOOM, BLAST)
  - 시스템: DING. 창 넘김: SWISH. 경보 징: DUM. 카운트다운: TICK.
- «KILL!!», «FIRE!!»처럼 대사급 단어를 효과음 크기로 화면을 가로질러 쓴다(3·7화 직접 봄).
- 한국어판 효과음 글자는 보지 못했다.

## 9. 전장 구도

- **성벽 위 시점**: 성가퀴 사이의 병사, 대포 포가, 화로, 찢긴 깃발(1화 직접 봄).
- **요새 부감**: 3화 전투 날 아침, 지그재그 회청색 성벽 위에 붉은 튜닉 병사가 점처럼 배치되고 바퀴 달린 대포·붉은 깃발·탑 위 지휘관이 보인다. 위에서 본 배치도 같다(3화 직접 봄).
- **성벽 공방**: 불길 너머로 내려다본 빽빽한 회청 갑옷 떼 ↔ 아래에서 올려다본 장미 문장 성벽과 기어오르는 푸른 유령불 갑옷 ↔ 붉은 깃발 아래 은투구·붉은 튜닉 군상을 번갈아 보여 준다(18화 직접 봄).
- **보스 규모**: 성벽 높이의 보스, 성벽에 비스듬히 박혀 남는 대검(20화 직접 봄).
- **승리 시선**: 하늘 → 깃발 → 주먹 → 햇살 비친 성벽 부감 → 병사 얼굴 → 성문 부감(HURRAH)으로 시선을 넓힌다(20화 직접 봄).
- (해석) 640×360 탑다운에서 가장 가까운 것은 3화 요새 부감이다. 지그재그 성벽 위 붉은 튜닉 점들, 산비탈에서 내려오는 검은 덩어리와 붉은 눈 점.

| 승리 | 없음 | 20화는 햇살 → 깃발 → 주먹 → 함성 → 검은 바탕 결산. 크게 잃은 8화는 숫자·장례 뒤 맨 끝에 결산 |
