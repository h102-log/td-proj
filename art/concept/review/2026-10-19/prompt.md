# 역할
너는 게임 캐릭터 아트 디렉터다. 첨부한 영웅 컨셉 시트 5장(첫 시안)을 검토하고,
그림을 그린 사람이 바로 고칠 수 있게 구체적으로 피드백해 줘.

# 첨부 파일
- 검토 대상(첫 시안): aias.png · seraphina.png · vesper.png · ignis.png · sylvia.png
- 승인된 기준작: chronos_ref.png. 같은 세계·화풍의 기준이다.
- 24px 실물: chronos_24px_ref.png(원본, 24px 크기 인물 칸 8개를 세로로 이은 시트), chronos_24px_ref_x8.png(8배 확대). 게임 안에서는 이 크기로 보인다.
- 소스 위치: sources.md(생성기 파일과 함수 목록). .py 소스가 함께 첨부돼 있을 수도 있다.

# 배경
- Godot로 만드는 타워 디펜스 게임이고, 스팀에 출시할 예정이다.
- 영웅은 3성 6명이다. 크로노스는 승인됐고, 나머지 5명이 이번 검토 대상이다.
- 게임 안에서 영웅은 24px 픽셀 스프라이트이고, f24p라는 32색 팔레트만 쓴다.
  - f24p 32색: 1f240a 39571c 2d472d efac28 efd8a1 ab5c1c 183f39 ef692f efb775 a56243 773421 724113
    2a1d0d 392a1c 684c3c 927e6a 276468 ef3a0c 45230d 3c9f9c 9b1a0a 36170c 550f0a 300f0a
    151a26 262d3d 3a4357 56607a 7a86a0 a4aec2 d0d6e0 4f78ad
  - 보라와 순백은 없다. 151a26은 외곽선에 쓰인다.
  - 시트 팔레트 칸에 작은 마름모가 찍힌 색이 f24p 색이다.
- 컨셉은 Python이 SVG를 직접 그리고, 헤드리스 Chrome으로 PNG를 찍는다.
  - 화면은 1920×1080이다. 인물 중심은 x≈960, 발바닥은 y≈996이다. y는 아래로 갈수록 커진다.
  - 너는 코드를 실행할 수 없다고 가정한다. 판단은 PNG로 하고, 고칠 위치는 sources.md의 함수 이름으로 짚어 줘.
- 시트 구성은 모두 같다: 가운데 전신 그림, 왼쪽 위 이름·이명·역할·대사, 오른쪽 확대 원 3개, 왼쪽 아래 팔레트.

# 영웅별 정보
각 영웅의 [고정]은 디렉터가 직접 고른 결정이니 바꾸자고 하지 마라.
[기본값]은 그린 사람이 임의로 정한 것이라 자유롭게 비판해도 된다.

1. 아이아스 — 탱커, «강철의 성채»
   - [고정] 그리스 영웅 × 아케인 강철 / 창 / 얼굴을 가린 코린트식 투구 + 진홍 깃 / 강철·금·진홍 포인트
   - [기본값] 세운 창과 땅에 세운 탑 방패, 등 뒤 빛의 성벽, 발밑 룬 원, 대사 «Where I stand, the line holds.»
   - 그린 사람이 본 약점: 정면 직립이라 딱딱하다 / 흉갑이 은색 조각상처럼 보인다 / 성벽이 빛보다 돌담으로 읽힌다 / 무릎 보호대가 단추 같다
2. 세라피나 — 힐러, «새벽빛의 성녀», 여성
   - [고정] 새벽 성당의 성녀 / 해 원반 지팡이 / 흰 베일 + 해 모양 관 / 상아·금·새벽 주황
   - [기본값] 감은 눈과 옅은 미소, 적갈색 머리, 등 뒤 장미창, 손바닥 위 빛 구슬, 대사 «Every night yields to the dawn.»
   - 그린 사람이 본 약점: 정면 직립 / 장미창이 머리 바로 뒤라 후광처럼 읽힌다 / 기둥·아치가 문틀 같다 / 치마 아래가 넓은 단색 면 / 주먹이 벙어리장갑 같다
3. 베스퍼 — 디버퍼, «그림자 역병의 설계자»
   - [고정] 역병 의사 학자 / 사슬 달린 독 향로 / 챙 넓은 모자 + 새부리 가면 / 흑갈 가죽·뼈색·독 녹
   - [기본값] 컴퍼스로 공중에 저주 도면(7각 별)을 긋는 자세, 역병 도시와 늪 배경, 대사 «Every plague begins on paper.»
   - 그린 사람이 본 약점: 정면 직립 기둥형 / 코트 아랫단이 넓은 어두운 면 / 어깨 망토가 밋밋하다 / 24px에서 흑갈 몸이 어두운 배경에 묻힐 우려
4. 이그니스 — 마법사, «원소의 지배자», 20대 초반 여성
   - [고정] 원소 대마법사 / 몸 둘레를 도는 불·서리·비전 구슬 셋 + 맨손 / 위로 솟은 불꽃 머리 / 주홍 로브·숯빛 안감·금
   - [기본값] 든 손 위의 화염구, 내린 손의 서리 파편, 밤하늘 운석우 배경, 금빛 눈과 한쪽 입꼬리 미소, 대사 «All elements answer to me.»
   - 그린 사람이 본 약점: 로브가 긴 원뿔이라 정적이다 / 뒷머리가 불꽃 장식처럼도 읽힌다 / 비전 구슬이 토성 같다 / 얼굴이 작아 표정이 약하다
5. 실비아 — 원거리, «취풍(翠風)의 명사수», 20대 여성
   - [고정] 바람의 순찰자 / 키만 한 리커브 장궁 / 내린 후드 + 날리는 포니테일 / 비취 청록·밝은 가죽·은
   - [기본값] 반측면으로 시위를 당긴 자세, 바람 나선이 감싼 화살, 고원 풀밭 배경, 먹빛 흑발, 대사 «Read the wind. Find the weakness.»
   - 그린 사람이 본 약점: 다리가 길고 곧아 뻣뻣하다 / 웃옷 자락이 망토와 같은 청록이라 섞인다 / 배경도 청록이라 망토가 묻힐 우려

# 검토 기준(중요한 순)
1. 실루엣과 24px 가독성: 24px·32색으로 줄여도 누구인지 알아볼 수 있나. 무엇이 살아남고 무엇이 사라지나.
2. 영웅 간 구분: 6명(크로노스 포함)을 나란히 놓았을 때 실루엣·주색·소품이 겹치지 않나.
3. 역할이 보이나: 탱커·힐러·디버퍼·마법사·원거리가 그림만 보고 읽히나.
4. 그림의 완성도: 비례, 자세의 생동감, 손·얼굴, 넓은 단색 면, 소품의 형태.
5. 시트의 통일성: 크로노스와 같은 세계·화풍으로 보이나.

# 출력 형식
영웅마다 아래 순서로 써 줘.
- 한 줄 총평
- 유지할 것: 고치지 말아야 할 강점 2~3개
- 고칠 것: 표(우선순위 상/중/하 | 무엇이 문제인가 | 왜 문제인가 | 어떻게 고칠까 | 코드 위치)
  - 우선순위 '상'은 3개 이내로 한다.
  - '어떻게'는 방향만 말하지 말고 구체적으로 쓴다. 예: "무릎을 20px 더 굽혀 보폭을 넓힌다", "장미창을 화면 왼쪽으로 옮겨 머리와 겹치지 않게 한다".
  - '코드 위치'는 sources.md의 함수 이름이다. 예: sylvia.py leg(), seraphina.py rose_window()
- 24px 판정: 줄였을 때 남을 핵심 특징 2개, 사라지거나 뭉갤 위험 1개

마지막에 «공통» 절을 따로 둔다.
- 영웅 간 겹침
- 다섯 명에게 공통으로 반복되는 문제(예: 정면 직립)
- 고칠 순서 추천
