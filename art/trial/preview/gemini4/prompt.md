# 배경
- Godot로 만드는 타워 디펜스 게임이고 스팀에 낸다. 화면은 640×360을 정수배로 키운다. 유닛은 24px다.

- 스프라이트는 손으로 찍지 않는다. Python이 3D 형체(타원체·캡슐·상자 SDF)를 목표 크기로 직접 렌더한다.
  - 음영은 재질마다 팔레트 색 4단(빛 방향: 왼쪽 위·카메라 쪽)이다. 바깥 외곽선은 가장 어두운 색 151a26이고, 안쪽 외곽선은 깊이 차가 큰 곳에만 생긴다.

  - 그래서 치마·로브·코트 자락도 윗몸에 붙어 움직이지 않는다.

  - 그래서 스프라이트에는 손에 든 물건과 몸 동작만 있다. 단, 아이아스 찌르기 프레임의 밝은 두 줄 잔상은 스프라이트에 구웠다.

# 영웅별 정보
[컨셉]은 사용자가 승인한 컨셉 아트에서 온 것이다. 24px에서 무엇을 남길지는 비판해도 된다.
[Claude 판단]은 만든 사람이 혼자 정한 것이라 자유롭게 비판해도 된다.

1. 아이아스 — 탱커, 근접(창). 기사 자리.
   - [컨셉] 코린트식 투구 + 진홍 깃, 판금 강철, 진홍 망토, 금테 탑 방패, 창
   - [Claude 판단] 창을 앞으로 15° 기울여 세워 든다. 공격은 창 찌르기: f1 허리 높이로 당김 → f2 팔을 뻗고 반 발 내디딤(잔상 두 줄) → f3 반쯤 거둠. 쓰러짐은 f3에 창을 놓치고 f4부터 방패가 몸 옆 바닥에 눕는다. 흉갑 마름모·방패 성가퀴·불씨 눈빛은 뺐다.
   - 만든 사람이 본 약점: SE에서 창이 몸을 가로지른다 / S·N 잔상이 약하다 / 캔버스 34px로 가장 크다 / 쓰러진 뒤 방패가 바닥에 남는다
2. 세라피나 — 힐러, 원거리(사거리 3). 여성.
   - [컨셉] 흰 베일 + 해 모양 관, 상아 옷, 앞 가운데 새벽 주황 속치마·영대, 금 단, 종 소매, 해 원반 지팡이, 손바닥 위 빛 구슬
   - [Claude 판단] f24p에 흰색이 없어 상아 efd8a1 + 그늘 927e6a. 얼굴 양옆에서 가슴 앞으로 내려오는 적갈색 머리 두 가닥. 공격은 f1 지팡이를 뒤로 눕혀 낮게 → f2 머리 위로 곧게 치켜들고 해 원반 1.6배, 왼손은 과녁 쪽 → f3 반쯤 내림. 과녁 쪽으로 겨누면 S에서 지팡이가 화면 아래로 짧아져 안 보여서 치켜들기로 했다.
   - 만든 사람이 본 약점: N·NE·NW 뒷모습이 상아 판에 지팡이뿐 / 지팡이와 몸 사이 1px 틈이 검은 세로줄처럼 보인다(S·SW) / 공격 f1이 N·NE에서 지팡이가 거의 안 보인다
3. 베스퍼 — 디버퍼, 원거리(사거리 3.5). 역병 의사.
   - [컨셉] 챙 넓은 모자, 뼈색 새부리 가면, 독녹 렌즈, 앞이 열린 흑갈 코트(독녹 안감), 뼈색 조끼, 어깨 망토, 사슬 독 향로, 컴퍼스
   - [Claude 판단] 가죽은 흑갈보다 한 단계 밝게(684c3c·927e6a). 오른손 향로, 왼손 컴퍼스. 공격은 f1 향로를 뒤로 낮게 → f2 팔을 곧게 들어 향로를 머리 위로 휘돌리고 독녹 띠 1.4배 → f3 앞으로 내림.

4. 이그니스 — 마법사, 원거리(사거리 4). 20대 여성.
   - [컨셉] 위로 솟은 불꽃 머리, 주홍 로브(숯빛 안감·금 단), 넓은 앞 트임 사이 숯빛 다리, 든 손 위의 화염구, 내린 손의 서리
   - [Claude 판단] 불꽃 머리는 곧은 다섯 갈래(뿌리 주황, 끝 노랑). 화염구는 팔을 옆으로 벌려 머리 옆에 든다(머리 위로 들면 불꽃 머리와 붙었다). 공격은 f1 화염구를 머리 뒤로 → f2 반 발 내디디며 앞으로 던짐(1.5배) → f3 빈손(화염구 없음). 원소 구슬 셋·궤도는 이펙트 몫으로 뺐다.

5. 실비아 — 원거리(사거리 4), 궁수. 20대 여성.
   - [컨셉] 비취 청록 웃옷·가죽 코르셋, 비취 망토, 등의 화살통, 먹빛 흑발 포니테일, 키만 한 리커브 장궁, 런지로 시위 당기기
   - [Claude 판단] 정지·걷기에서 활을 몸 왼쪽에 세우고 시위를 바깥으로 둔다(몸 쪽이면 S에서 시위가 몸통 위 은색 줄이었다). 공격은 세 프레임 모두 런지: f1 활을 과녁 쪽에 세우고 시위를 뺨까지 당김(화살 보임) → f2 놓음(시위 곧음, 화살 없음, 오른손이 귀 뒤로) → f3 활을 조금 내림. 스카프·후드·멜빵은 뺐다.
   - 만든 사람이 본 약점: E·W에서 활이 시위와 겹친 세로 막대 / 가죽 갈색 점이 많아 얼룩져 보일 수 있다 / 공격 f1에서 활·시위가 몸통에 겹쳐 복잡하다
