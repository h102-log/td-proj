개발 중인 2D 도트 타워 디펜스 게임(성 방어)의 새 적 스프라이트 시안을 냉정하게 검토해 줘. 칭찬보다 문제를 찾는 것이 목적이다.

게임 조건
- 위에서 45° 내려다보는 시점. 기준 화면 640×360을 창 1280×720(2배)에 그린다. 맵 한 칸은 16px, 적 스프라이트 캔버스는 24px 기준이다(큰 것은 더 크다).
- 적은 화면 아래(남쪽)에서 올라와 위(북쪽)의 성벽·성문을 친다. 그래서 게임에서는 주로 북쪽을 보는 그림(뒷모습)이 보인다.
- 그림은 3D 형체(상자·캡슐·타원체)를 코드로 구워 만든 도트이고, 팔레트는 32색 고정이다.

첨부
- 1번 `01_sheet_numbered`: 9개 줄(왼쪽 번호 1~9). 줄마다 한 종류를 남·동·북·서(왼쪽부터) 방향에서 본 정지 그림이다. 5배 확대.
- 2번 `02_ingame_mock`: 실제 게임 화면(1280×720) 위에 실제 크기로 얹은 장면. 위쪽 회색 띠가 성벽(앞면은 아래쪽 어두운 벽돌면), 가운데 주황 아치가 정문. 붉은 가는 선은 준비 단계의 적 경로 미리보기라 무시해도 된다. 작은 잿빛 고블린 넷은 이미 게임에 있는 기본 적이다.
- 3번 `03_sizes_gray`: 크기 비교. 위에서부터 남쪽·회색조·동쪽·회색조·북쪽·회색조 줄. 줄마다 왼쪽 9개가 1~9번 순서이고, 오른쪽 끝 셋은 이미 게임에 있는 기본 적·장갑 적·보스다. 나는 것은 발밑에 그림자 원을 깔았다.
- 4번 `04_night`: 남쪽 그림을 낮·밤 반쯤·밤(불빛 가장자리)으로 어둡게 한 것.

아직 각 줄이 무엇인지는 알려 주지 않는다. 먼저 블라인드로 답해 줘.
1. 1~9 줄마다: 무엇으로 보이는가(사물·생물, 게임에서 무엇을 할 것 같은가), 확신도(상·중·하), 그렇게 본 근거(어느 방향 그림의 어떤 부분인지).
2. 2번 장면에서 각 줄의 그림을 찾아라. 찾은 것마다 생김새와 대략 위치(1280×720 좌표)를 함께 말하고, 못 찾거나 헷갈리는 것은 그렇다고 말해라.
3. 9종이 한 세력(같은 무리)으로 보이는가, 아니면 서로 다른 무리로 보이는가. 근거는?
4. 방향에 따라 다른 물체로 읽히는 줄이 있는가(예: 어느 방향에서만 막대처럼 보임).
