# 05. 상태이상·장판·예고 표시 비교

[README](README.md)로 돌아가기.

[01](01_principles.md)~[04](04_sprite_games.md)에서 이 세 가지만 모아 비교한다. 우리 화면에서 가장 지저분한 곳(상태 고리 3~4겹)과 가장 오래 떠 있는 곳(장판)이라 따로 묶었다.

---

## 1. 상태이상

### 1.1 다른 게임은 어떻게 보이나

| 게임 | 방식 | 겹칠 때 |
|---|---|---|
| StarCraft | 유닛 위에 얹는 **재질 오버레이**(흘러내리는 방울, 균열 구체, 앞·뒤 두 장), S/M/L 세 벌 | 오버레이마다 시작이 무작위라 박자가 엇갈린다. 같은 효과의 중첩은 다른 그림으로 보인다(Acid Spores) |
| Mindustry | 몸 안 무작위 지점에서 **작은 파티클**(반경 1~2.5 unit)을 tick마다 확률 0.09~0.15로 낸다. 상태마다 모양(원·마름모·사각형)과 곡선이 다르다. 감속에는 표시가 없다 | 파티클이 섞여 나올 뿐 겹이 쌓이지 않는다(추론) |
| SPD | 몸에서 나오는 상태(불·냉기·표식·치유)는 **파티클**, 몸이 바뀌는 상태(빙결·암흑·발광·투명·마비)는 **틴트·밝기·정지**. 남은 시간은 7px **UI 아이콘** | 같은 방식끼리 겹치는 경우가 드물다(추론) |
| Into the Breach | **26px 아이콘**(1px 외곽선 + 3~13색 + 어두운 후광) | 아이콘을 늘어놓는다(추론) |
| Kingdom Rush | **전체 색조**(화상·빙결) + **발밑 장식**(감속) + **머리 위 입자**(기절) + 만화 글자 | 서로 다른 상태는 함께 걸리고, 같은 상태는 쌓이지 않는다(팬 위키) |
| FFT | 상태마다 **상징 하나**, 일부는 **스프라이트 교체** | 확인 못 함 |
| LoL(원칙) | 효과가 비슷하면 같은 시각 언어. 속박은 바닥 고리 + 솟는 원통, 기절·독·침묵은 게임 관습대로. 강한 CC일수록 강하게 | — |

**공통점:** 순수 RGB 고리를 겹쳐 쌓는 게임은 하나도 없었다. 모두 상태마다 **표현 수단 하나**(재질 오버레이·파티클·틴트·아이콘)를 배정하고, 수단을 나눠서 겹쳐도 서로 가리지 않게 한다.

### 1.2 우리 지금

- 적 8종(기절·속박·둔화·받는 피해 증가·도발·봉인·사슬·초당 피해)과 아군 4종(받는 피해 감소·공격 속도·보호막·불사)을 모두 **몸 둘레 1px 고리**로 그린다. 효과마다 0.15칸씩 바깥으로 한 겹 늘어난다(`src/ui/battle_view.gd:302-313`, I101).
- 색은 `Color.YELLOW`·`CYAN`·`MAGENTA`·`RED`·`ORANGE`·`GOLD` 같은 순수 RGB다(`:20-22`).
- 창 해상도로 그리므로 고리가 화면 픽셀로 매끈하다([06 §1](06_godot_tech.md), [그림](img/now_ignis_e_crop3x.png)).

### 1.3 우리 상태 12종에 수단 배정 (추론, 시안 전 초안)

[01](01_principles.md)의 위계를 따른다. CC가 1차, 나머지는 2차다.

| 상태 | 위계 | 수단 후보 | 참고 |
|---|---|---|---|
| 기절 stun | 1차 | 머리 위에 도는 별·전기 입자 2~3개 + 몸 정지 | KR 기절, SPD 마비(정지) |
| 속박 root | 1차 | 발밑 고리 + 솟는 짧은 기둥(덩굴·쇠사슬) 재질 | LoL 속박 관습 |
| 도발 taunt | 1차 | 머리 위 작은 아이콘(분노 기호) | ITB 아이콘 |
| 봉인 seal | 1차 | 머리 위 작은 아이콘(자물쇠·금지) | ITB 아이콘 |
| 둔화 slow | 2차 | 발밑 얼음 파편·서리 장식 | KR 감속 |
| 받는 피해 증가 expose | 2차 | 몸 틴트 깜빡임(1Hz) 또는 작은 균열 오버레이 | SPD 발광 맥동 |
| 사슬 chain | 2차 | 지금의 적끼리 잇는 선을 사슬 고리 도트로(영혼 사슬) | SPD 사슬 스프라이트 |
| 초당 피해 dot | 2차 | 몸에서 피어오르는 작은 사각형 파티클(독 = 녹색 방울, 불 = 주황 불티) | Mindustry 불탐·SC 고 |
| 받는 피해 감소 dr | 2차 | 몸 앞뒤로 끼우는 방패 일렁임 | SC Defensive Matrix |
| 공격 속도 haste | 2차 | 발에서 오르는 작은 사각형 | Mindustry overdrive |
| 보호막 shield | 2차 | 몸 둘레 테 하나(단, 아트 px·팔레트 색) | SPD ShieldHalo |
| 불사 invuln | 1차(아군 시점) | 금색 실루엣 테두리 + 맥동 | KR 색조 |

- 남은 시간·중첩 수가 꼭 필요하면 아이콘 줄로 옮긴다(SPD·ITB). 지금 HUD 정보 칸이 이미 있다면 그쪽이 낫다(추론).
- 오버레이·파티클 시작 박자는 사건 번호 해시(`_h`)로 어긋나게 한다(SC 무작위 대기와 같은 효과).

## 2. 장판(지속 범위)

### 2.1 다른 게임은 어떻게 보이나

| 게임 | 장판을 그리는 법 | 경계 |
|---|---|---|
| StarCraft | 덩어리 구름·흩뿌린 방울. 펼침(1틱씩 빠르게) → 유지(3틱씩 느린 왕복) → 흩어짐. 불투명이면 성기게(0.11~0.55), 반투명이면 조회표 | 원 테두리 없음 |
| Into the Breach | 타일 그림을 질감으로 통째로 바꾼다. 산성 웅덩이는 계단식 3단 알파 | 타일 경계 |
| SPD | 칸마다 주기적으로 파티클을 하나씩 뿌린다(불 0.03초, 독가스 0.4초) | 칸 모양으로 불규칙 |
| Mindustry | 웅덩이는 불투명 원 + 위성 원 3개. 구름은 원 80개를 앞뒤 10%만 페이드 | 불규칙 |
| Kingdom Rush | 얼음 파편·균열·독 웅덩이를 바닥 장식으로 | 장식 가장자리 |
| LoL(원칙) | **테두리가 1차**(선명·불투명), **안쪽이 2차**(옅고 약하게). Leona W | 판정 경계 = 테두리 |

### 2.2 우리 지금과 비교

- 지금: 18% 알파 원판 + 0.9 알파 기호 무늬(^·나선·물결·빗금·십자·X) + 0.8 알파 1px 테두리(`:270-278`, `_pattern` `:1792~`). 무늬는 굵기를 주지 않은 `draw_polyline`이라 화면 1px 머리카락 선이다.
- 장판을 무늬로 가르기로 한 것은 사용자 결정이다(2026-10-19, WBS 4.1f). 비슷한 색 쌍(불길·용암, 블랙홀·늪, 화살비·독안개, 황금률·성역)을 가르려는 목적이었다.
- 다른 게임에 비추면(추론)
  - 그 목적은 **재질**로 더 잘 이룰 수 있다. 불길은 솟는 불꽃 조각, 용암은 어두운 균열 + 밝은 심, 독안개는 성긴 증기 조각, 늪은 진흙 거품, 화살비는 꽂힌 화살 도트, 성역은 바닥 문양, 블랙홀은 안으로 모이는 조각, 황금률은 바닥 햇살 문양, 왜곡장은 시계 눈금 조각이다. 기호보다 재질이 «무엇인지»를 바로 말해 준다.
  - 경계는 **1차 테두리**로 따로 둔다. 판정이 칸 원이므로 아트 px 원 테두리를 팔레트 색 2단(밝은 선 + 어두운 밑칠, Mindustry `Drawf.circles`)으로 긋는다.
  - 안쪽 판은 18% 알파 대신 **성긴 불투명 조각**이나 **계단 알파 2~3단**으로 한다(SC·ITB).
  - 펼침·유지·사라짐 박자를 나눈다(SC). 지금 장판은 깔리는 순간 다 그려지고 끝나는 순간 사라진다.

## 3. 예고(보스 스킬·위험)

| 게임 | 예고 | 발동 |
|---|---|---|
| Into the Breach | 대상 타일에 사선 줄무늬(6px 주기), 공격자 빨간 외곽선, 순서 숫자, 경로 점, 밀림 화살표 | — |
| SPD | 보스(Goo)는 위험 칸마다 검은 파티클을 뿜는다. 공격 예정 칸은 발동 전까지 알파 0.6 밑으로 내려가지 않는다 | 발동 순간 칸마다 버스트 + 소리 |
| Mindustry | 충전: 파티클·선이 **안으로 모이고** 흰 심 원이 커진다. 줄어드는 고리 | 퍼지는 버스트 |

| LoL 원칙 | 피할 수 있는 스킬일수록 시선을 끈다. 바닥 표시는 판정과 맞아야 한다 | — |

- 우리 지금: 빨간 테두리 안쪽이 남은 시간만큼 차오르고(`:279-285`, S194), 발동하면 처음 몇 프레임은 예고 모양을 예고색으로 채운다(`_fills`, `:286-287`). 실제 판에서 «강한 순간» 1위였다(`insights/2026-10-22_hit_feel.md`). **예고의 구조는 이미 좋다.**
- 다듬을 점(추론)
  - 차오르는 채움을 반투명 원판(알파 0.35) 대신 ITB식 **사선 줄무늬**나 **안으로 모이는 조각**으로 하면 도트 화면에 맞으면서 «다가온다»가 더 분명하다.
  - 테두리는 창 해상도 원이라 다른 이펙트와 같은 mixel 문제가 있다. 아트 px 원 + 어두운 밑칠로 바꾼다.
  - 발동 직전 1프레임 흰 섬광(Saint11의 white flash)을 넣는다. 다만 번쩍임 줄이기 설정(S237)을 따라야 한다.
  - 빨간 예고색 `TELL`은 보스 전용 신호로 남긴다. 다른 이펙트에 쓰지 않는다(ARPG «같은 색은 같은 결과»).
