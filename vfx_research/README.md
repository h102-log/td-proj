# 이펙트 조사 — 다른 게임은 스킬 이펙트를 어떻게 그리나 (2026-10-27)

## 0. 결론 먼저

요청(사용자 2026-10-27): «영웅 이펙트 개선해보자. 지금은 너무 그림판에 그린듯한 너무 조잡한 이펙트임», «다른 게임들 조사해서 이펙트를 참고해보자».

### 왜 조잡해 보이나

1. **해상도가 섞였다.** 10/25부터 맵을 창 해상도로 그린다(S30 변경). 그래서 도트 유닛 옆에 원은 화면 픽셀로 매끈하게, 장판 무늬는 화면 1px 머리카락 선으로 그려진다. 실행 화면으로 확인했다([06 §1](06_godot_tech.md), [그림](img/now_ignis_e_crop3x.png)). 무늬는 S168 «맵 1px»와도 어긋난다.
2. **움직임이 한 단계뿐이다.** 모든 흔적이 «굵기 고정 고리가 커지며 옅어짐» 하나다.
3. **한 색에 알파, 그것도 팔레트 밖 순수 RGB다.**
4. **위계가 없다.** 상태 12종이 같은 1px 고리로 3~4겹 쌓인다.
5. **장판 무늬가 재질이 아니라 기호다.**

### 다른 게임에서 확인한 것

- **코드로 그려도 된다.** Mindustry는 이펙트를 거의 다 선·원 도형으로 그린다. 다만 이런 기법을 쓴다([03](03_code_drawn_games.md)).
  - 굵기를 1 → 0으로 줄이고 반경을 빠르게 키운다.
  - 짧은 충격(앞 6 tick)과 긴 잔해를 나눈다.
  - 고리 + 연기 + 불티 + 빛을 겹친다.
  - 흰 심을 넣고, 밝은 색·진한 색 짝을 쓴다.
  - 표시물 밑에 3px 회색을 깐다.
- **도트 이펙트는 단계와 색 램프로 만든다.** Saint11 폭발은 어두운 섬광 → 흰 섬광 → 날카로운 터짐 → 빨리 사라지는 불·천천히 사라지는 연기, 최소 4프레임, 7색이다. 사라질 때는 알파 대신 어두운 색을 쓴다([02](02_pixel_craft.md)).
- **반투명 원판은 아무도 안 쓴다.** StarCraft Psionic Storm은 6색 번개가 bbox의 11%만 칠한다. 불투명 장판도 34~55%만 칠한다. Into the Breach 산성은 알파 세 단계다([04](04_sprite_games.md)).
- **상태이상을 고리로 쌓는 게임은 없다.** StarCraft는 재질 오버레이(S/M/L), Mindustry는 몸에서 나오는 파티클, SPD는 파티클·틴트, Into the Breach는 26px 아이콘, Kingdom Rush는 색조·발밑 장식·머리 위 입자를 쓴다([05](05_status_and_zones.md)).
- **위계 원칙(Riot).** 시선은 중요도에 비례한다. 판정 테두리는 1차(선명·불투명), 안쪽은 2차(옅게)다. «모든 것이 중요하면 아무것도 중요하지 않다»([01](01_principles.md)).
- **해상도가 같은 게임이 있다.** Into the Breach와 Wargroove는 원본이 640×360이다. 크기 비교의 기준으로 쓸 수 있다.

### 제안

- **방향은 C(코드 + 작은 스프라이트)를 추천한다.** 순간 이펙트는 지금 `_draw`에서 위 기법으로 다시 쓴다. 결이 있는 재질(불꽃·증기·균열·번개 결·상태 아이콘)만 7~16px 아틀라스 조각으로 그린다. 코드 게임(SPD)과 스프라이트 게임(StarCraft)이 같은 구성으로 수렴했다.
- **해상도 섞임(P1)은 따로 떼어 먼저 고칠 수 있다.** 원·선을 아트 px로 그리는 도우미 하나로 고친다. S168 회귀를 바로잡는 일이기도 하다.
- 결정 질문 여섯(방향, 장판 무늬, 상태 표시, 팔레트, 순서, 일정)과 스킬 유형별 아이디어는 [08](08_for_our_game.md)에 있다. 다음 단계는 이그니스 한 명으로 «지금 / A / C» 시안을 만드는 것이다.

## 범위와 한계

- 게임 사례는 그림·소스로 잰 것이다. 실제 재생 길이(초)는 StarCraft(틱)·Mindustry(tick)·Saint11(80ms) 말고는 거의 확인하지 못했다.
- Riot 원칙은 PvP MOBA에서 나왔다. 플레이어가 적에게 CC를 거는 싱글 디펜스에는 범위를 따로 판단해야 한다.
- 무료 팩은 zip을 열어 보지 않았다.
- 이 폴더는 제안이다. SPEC·코드는 바꾸지 않았다. 난이도·밸런스 측정은 프로젝트 규칙대로 넣지 않았다.
