# 2026-10-20 — 4.2 메인 메뉴·ESC 메뉴·설정·진행 저장

## 질문

WBS 4.2는 메인 메뉴, ESC 일시정지, 설정(퀵캐스트, S147), 진행 저장이다. 완료 확인은 «이어하기로 저장한 도전이 복원된다»다.

## 지금 모습에서 확인한 것

- 게임을 켜면 바로 영입 창이 떴다. 메뉴·일시정지·설정·저장은 없었다. 설정 자리에 쓸 값은 부활(`battle.revive`, I28)뿐이었다.
- 웨이브가 끝나면 장판·효과·보호막·스킬 지시를 지우고(`_clear_effects`), 공병 일을 놓아준다(`_release`). 그래서 전투 단계가 아닐 때는 적이 없고, 유닛·구조물이 서로 가리키는 칸도 없다.
  - 저장할 것은 구조물·성곽·잔해·거점·용병·영웅의 값과 판 전체 값(단계·라운드·골드·영입 목록·미션·난수 상태)뿐이다.
  - 전투 중 저장은 적·장판·효과와 그것들이 서로 가리키는 대상까지 담아야 해서 몇 배 크다(Claude 판단).
- 관찰 하네스(`tools/play`)와 유닛 테스트는 `main.tscn`을 직접 붙인다. 메뉴를 같은 장면에 넣으면 이들이 메뉴부터 만나게 된다.

## 사용자 결정

| 결정 | 고른 안 | 다른 안 |
|---|---|---|
| 저장 시점 | 전투 단계가 아닐 때마다: 영입 창·준비 단계·라운드 사이가 될 때, 웨이브 시작 직전, 그때 나갈 때(S181). 전투 중에 나가면 그 웨이브 시작 직전으로 돌아간다 | 라운드 사이만 / 전투 중 포함 언제든 |
| 메인 메뉴 | 새 게임·이어하기·설정·종료(S182) | 새 게임·이어하기만 |
| ESC 메뉴 | 계속·설정·메인 메뉴로·게임 종료(S183) | 게임 종료를 뺀 셋 |
| 설정 | 퀵캐스트·부활·창 모드·음량 넷 다(S184) | — |

- 저장 시점은 지기 직전에 나가 그 웨이브를 다시 할 수 있다는 것을 알고 골랐다.

## 만든 것(S181~S184, I156~I161)

- 장면: 게임을 켜면 `src/menu.tscn`(메인 메뉴)이 뜨고, 새 게임·이어하기를 고르면 `src/main.tscn`(게임)으로 간다. 하네스·테스트는 지금처럼 `main.tscn`을 직접 붙이고, 그때는 저장 경로가 비어 있어 아무것도 쓰지 않는다.
- `src/sim/save.gd`: 판을 사전으로 떠서(`snapshot`) 같은 스테이지의 새 판에 되돌린다(`apply`). 유닛·구조물은 스크립트 변수를 모두 담고, 다른 객체를 가리키는 칸(지난 공격 대상 등, `SKIP`)만 뺀다. 새 칸이 생겨도 따로 손대지 않아도 담긴다.
  - 파일은 `user://save.dat` 하나다. 임시 파일에 다 쓴 뒤 바꿔 넣고, 바꾸는 사이에 꺼져 임시 파일만 남으면 그것을 읽는다. 형식 판(`version`)이 다르거나 깨진 파일은 저장 없음으로 본다.
- `src/main.gd`: 판 단계가 바뀔 때 전투 단계가 아니면 저장하고, 지거나 도전에 성공하면 지운다. 웨이브 시작 직전은 `Battle.wave_starting` 신호로 저장한다. 조준·놓기·대포 옮기기 중이 아닐 때 ESC가 ESC 메뉴를 열고 트리를 멈춘다(I11).
- `src/ui/menus.gd`: 메인 메뉴·확인 창·ESC 메뉴·설정을 그리는 CanvasLayer(층 2, HUD 위)다. 트리가 멈춰도 돈다. ESC는 한 단계 뒤로 간다(I159).
- `src/settings.gd`: 설정 넷을 `user://settings.cfg`에 둔다. 창 모드는 고른 적이 없으면 null이고, 그때는 S163대로 시작한다. F11로 바꾼 모드도 남는다.
- `src/ui/controls.gd`: 퀵캐스트가 켜져 있으면 Q·W·E·R 키를 누르는 순간 커서 자리에 쓴다. HUD 스킬 버튼은 조준 상태로 남는다(I158).

## 확인

- 평가 EV306~EV318이 green이다. final은 green 295 · missing 22 · red 1(기존 기각 EV174)이다.
  - EV306: 실비아·아이아스를 영입해 Q를 쓴 판을 준비 단계와 라운드 사이에 저장하고 새 판에 불러온다. 두 판에서 다음 웨이브를 20초 돌리면 골드·거점·적·유닛·구조물·성곽이 모두 같다.
  - EV306을 일부러 망가뜨려 확인했다. 골드·난수 상태·재사용 대기·마나를 담지 않으면 실패한다. 처음 시나리오(스킬을 쓰지 않음)는 재사용 대기와 난수를 놓쳐 시나리오를 바꿨다.
- 평가 실행기(`tests/eval/gd/runner.gd`)는 이제 첫 프레임에 ev를 돌린다. `_initialize` 때는 붙인 장면의 `_ready`가 돌지 않아서다. 기존 282개 결과는 그대로였다.
- 게임을 띄워 찍었다: 메인 메뉴(이어하기 흐림), 설정, 영입 창 위 ESC 메뉴, 전투 중 ESC 메뉴(«저장되지 않습니다» 안내), 확인 창, 이어하기한 준비 단계. 처음에는 메뉴가 왼쪽 위에 붙고 HUD 밑에 깔렸다. 그래서 CanvasLayer(층 2)로 바꾸고 크기를 앵커와 오프셋으로 정했다.
- 설정의 «전체화면»을 켜면 창이 전체화면이 되고, 끄면 S161 크기(4K에서 3200×1800) 창으로 돌아갔다.
