## 질문

사용자 결정(2026-10-18): 크로노스 컨셉 아트([art/concept/chronos](../art/concept/chronos/README.md))를 **장군 외형으로 쓰고 24px 스프라이트로 옮긴다.**

설정은 4.0 확정값을 따른다([2026-10-18 아트 시험](2026-10-18_art_trial.md)): 45°, 외곽선 D, f24p, 유닛 24px(배율 17.47).

## 확인한 것

### 한 것

| 파일 | 바꾼 것 |
|---|---|
| `tools/art/hero.py` | 기사 함수에서 관절 계산을 `rig()`(공용 뼈대)로, 검 방향을 `blade_axes()`로 꺼냈다. `fit`·`bake`·`fits`·`save`가 형체·재질·폴더를 인자로 받는다. 기본값은 기사다. 재질 값 자리에 f24p 색 5개 목록(손 램프, `ramp()`)을 쓸 수 있다 |

| `tools/art/lint.py` | 둘째 인자로 영웅 모듈을 고른다. 걷기에서 다리 말고는 모두 «윗몸»으로 본다(기사는 이전과 같은 부위 묶음) |

- 시트(45°·D·f24p·24px)는 기사와 같은 배치다.
  - 정지 8방향
  - 걷기 8방향 × 4프레임
  - 공격 8방향 × 3프레임
  - 쓰러짐 1벌 × 5프레임
  - 공격·쓰러짐은 2배 캔버스다.
- 크로노스 자세는 기사의 자세를 그대로 쓰고 왼팔만 바꿨다. 오른팔은 검 자세 그대로 지휘봉을 들고, 왼팔은 모래시계를 띄운다. 공격은 뒤에 원거리 동작으로 바꿨다(아래 «공격 동작을 원거리로»).
- 16·32px은 굽지 않았다. 유닛 24px로 확정됐기 때문이다.
- 다시 굽기:
  ```
  python tools/art/chronos.py            # 시트
  python tools/art/chronos.py preview    # 미리보기
  python tools/art/lint.py walk_45_D_f24p chronos
  ```

## 공격 동작을 원거리로(사용자 2026-10-18)

크로노스는 원거리(S121 사거리 3)인데, 공격 시트는 기사의 검 내려치기(들어올림 → 내려침 → 회복, 내려칠 때 발을 내딛는다)를 빌려 썼다. 사용자가 원거리 동작으로 바꾸기로 했다.

| 지적 | 고친 것 | 결과 |
|---|---|---|
| 근접 내려치기 | 3프레임을 지휘자가 첫 박을 치는 동작으로 바꿨다. 준비는 팔을 곧게 위로 뻗어 지휘봉을 치켜든다. 발사(가운데, 타격 프레임)는 팔과 지휘봉을 과녁 쪽으로 곧게 뻗는다. 마무리는 조금 더 내리고 지휘봉을 바깥으로 15° 눕힌다. 발은 내딛지 않는다. 탄은 그리지 않는다. 게임은 지금 공격을 공격선(`battle_view.gd`)으로 보여 주고, 탄 이펙트는 4.1f 몫이다 | 동·서·북동·남서에서는 발사 프레임이 과녁 쪽으로 뻗은 선으로 읽힌다. 남·북에서는 과녁이 카메라 쪽·반대쪽이라 지휘봉이 아래·위로 보인다 |
| 지휘봉이 몸에 묻힘 | 지휘봉이 몸 실루엣 밖으로 나온 픽셀을 8방향마다 재서, 가장 적은 방향의 값이 큰 각도를 격자로 골랐다(준비 126안, 마무리 36안). 팔을 벌려 비스듬히 들면(sh_r 150·ab_r 0.5) 45°에서 팔이 화면 아래로 내려와, 동·북에서 지휘봉이 머리에 묻혔다 | 가장 적은 방향 기준으로 준비·발사·마무리가 3·5·3px다. 기사 자세를 빌렸을 때는 0·1·2px였다 |
| 쏘는 순간 | 발사 프레임만 지휘봉 끝 청록 구슬을 1.6배로 키웠다(자세 값 `tip`). 1배는 1px이라 티가 안 났고, 2배는 철퇴 머리처럼 보였다. 반 발 내딛기도 견줘 봤지만 24px에서 차이가 거의 보이지 않아 넣지 않았다 | 끝이 2px 청록으로 커진다 |
| 동작을 볼 곳 | 보기 화면(`viewer.gd`)에 크로노스 쪽이 없어 `preview/chronos_attack.gif`를 더했다. 보기 화면처럼 0.12·0.15·0.15초 뒤 0.58초 정지하고, 8방향을 두 줄로 보인다 | 미리보기가 4장이 됐다 |

검증: 정지·걷기·쓰러짐 시트(부위 이미지 포함)와 `fit.json`, 정지 비교·걷기 GIF 미리보기는 고치기 전과 바이트까지 같다. lint는 공격 H5 통과(테두리 닿음 0), 걷기 H3 8방향 0·H4 8방향 OK, 정지·쓰러짐 H5 통과다. 기사(`hero.py`)는 건드리지 않았고 lint도 그대로 통과한다. pyflakes 깨끗함.

## 판단

- 사용자 결정(2026-10-18): 장군 외형은 크로노스로 한다. 정한 것은 외형뿐이었다. 같은 날 SPEC이 영웅 6명을 바꾸면서(S157) 장군 자리를 크로노스(종류 `chronos`, 이명 «시계탑의 지휘관»)가 이었다. 그래서 게임 안 이름도 크로노스이고, 모듈·시트 폴더·미리보기 이름을 `general`에서 `chronos`로 고쳤다. 형체는 그대로라 다시 구운 시트 8장(부위 이미지 포함)과 미리보기 3장이 고치기 전과 픽셀 단위로 같다. 이 기록의 파일 이름은 그날 이름 그대로 둔다.
- (Claude 의견) 공용 뼈대는 쓸 만하다. 크로노스는 형체 함수와 왼팔 자세, 원거리 공격 자세만 새로 썼다. 맞춤·굽기·lint·걷기 규칙(윗몸 고정)은 기사 것을 그대로 썼다. 남은 영웅 4명과 용병도 같은 길로 간다.
- (Claude 의견) 컨셉의 상징(광륜)은 스프라이트보다 이펙트가 맞다. 게임은 이미 살아 있는 영웅 둘레에 오라 원을 그린다(S113). 크로노스의 오라 원(패시브 «가속의 오라», S158)만 시계 문자판 무늬(눈금 12개)로 그리면, 군중 속에서도 크로노스를 찾는 표지가 된다(4.1f 제안).
- (Claude 의견) 크로노스는 기사보다 어둡다. 몸통이 남색이라 들판에서는 실루엣이 또렷하지만, 밤 장면에서는 묻힐 수 있다. 4.1d의 아군 구분 규칙(팀 색·외곽선)을 정할 때 함께 본다.
