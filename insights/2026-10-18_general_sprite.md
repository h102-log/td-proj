# 2026-10-18 — 장군 스프라이트(크로노스 외형, B 방식 24px)

## 질문

사용자 결정(2026-10-18): 크로노스 컨셉 아트([art/concept/chronos](../art/concept/chronos/README.md))를 **장군 외형으로 쓰고 24px 스프라이트로 옮긴다.**
- 기사와 같은 뼈대·배율로 만들 수 있나? WBS 4.1d는 «인간형 공용 뼈대로 용병·영웅»을 만들기로 했다.
- 컨셉의 무엇이 24px(몸 약 14px)에서 남나?

설정은 4.0 확정값을 따른다([2026-10-18 아트 시험](2026-10-18_art_trial.md)): 45°, 외곽선 D, f24p, 유닛 24px(배율 17.47).

## 확인한 것

### 한 것

| 파일 | 바꾼 것 |
|---|---|
| `tools/art/hero.py` | 기사 함수에서 관절 계산을 `rig()`(공용 뼈대)로, 검 방향을 `blade_axes()`로 꺼냈다. `fit`·`bake`·`fits`·`save`가 형체·재질·폴더를 인자로 받는다. 기본값은 기사다. 재질 값 자리에 f24p 색 5개 목록(손 램프, `ramp()`)을 쓸 수 있다 |
| `tools/art/general.py` | 장군 형체·자세·굽기·미리보기. `art/trial/general/`에 시트 4장을 쓴다 |
| `tools/art/lint.py` | 둘째 인자로 영웅 모듈을 고른다. 걷기에서 다리 말고는 모두 «윗몸»으로 본다(기사는 이전과 같은 부위 묶음) |

- 시트(45°·D·f24p·24px)는 기사와 같은 배치다.
  - 정지 8방향
  - 걷기 8방향 × 4프레임
  - 공격 8방향 × 3프레임
  - 쓰러짐 1벌 × 5프레임
  - 공격·쓰러짐은 2배 캔버스다.
- 장군 자세는 기사의 자세를 그대로 쓰고 왼팔만 바꿨다. 오른팔은 검 자세 그대로 지휘봉을 들고, 왼팔은 모래시계를 띄운다.
- 16·32px은 굽지 않았다. 유닛 24px로 확정됐기 때문이다.
- 다시 굽기:
  ```
  python tools/art/general.py            # 시트
  python tools/art/general.py preview    # 미리보기
  python tools/art/lint.py walk_45_D_f24p general
  ```

## 판단

- 사용자 결정(2026-10-18): 장군 외형은 크로노스로 한다. 정한 것은 외형뿐이다. 게임 안 이름은 SPEC S97의 «장군» 그대로 두었다.
- (Claude 의견) 공용 뼈대는 쓸 만하다. 장군은 형체 함수와 왼팔 자세만 새로 썼다. 맞춤·굽기·lint·걷기 규칙(윗몸 고정)은 기사 것을 그대로 썼다. 남은 영웅 4명과 용병도 같은 길로 간다.
- (Claude 의견) 컨셉의 상징(광륜)은 스프라이트보다 이펙트가 맞다. 게임은 이미 살아 있는 영웅 둘레에 오라 원을 그린다(S113). 장군의 오라 원만 시계 문자판 무늬(눈금 12개)로 그리면, 군중 속에서도 장군을 찾는 표지가 된다(4.1f 제안).
- (Claude 의견) 장군은 기사보다 어둡다. 몸통이 남색이라 들판에서는 실루엣이 또렷하지만, 밤 장면에서는 묻힐 수 있다. 4.1d의 아군 구분 규칙(팀 색·외곽선)을 정할 때 함께 본다.
