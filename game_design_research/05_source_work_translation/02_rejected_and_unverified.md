# 원작 관련 기각·미확인 주장

리서치에서 기각된 주장 6건과 원작에서 확인되지 않은 영역을 정리하고, 기획서에 원작을 인용할 때 지킬 표기 규칙을 정한 문서.

**이 파일이 답하는 질문**
- 리서치에서 기각된 주장 6건은 각각 무엇을 주장했고, 왜 기획서에 인용하면 안 되는가?
- 기각된 주장 대신 같은 주제에서 인용할 수 있는 확인 주장은 무엇인가?
- 원작에서 확인되지 않은 영역(피로도, 적 등급별 대응 주체, 성벽 내구도 수치 관리, '병력은 시간 확보·영웅은 결정타' 일반 구조 등)은 어떻게 다뤄야 하는가?
- 기획서에 원작을 인용할 때 어떤 표기 규칙을 지켜야 하는가?

---

## 0. 판정 근거의 범위

- 1차 주장은 3표 반박 검증에서 2표 이상 살아남아야 확인으로 남는다([주장 대장](../99_appendix/claim_ledger.md) 머리말). 2차 주장(R2-C*)은 출처 대조와 독립 교차 확인의 2관점으로 재검증했고, '부분 확인'이면 과장을 걷어낸 수정 문장이 대장에 있다(같은 머리말).
- R1-X1(기각됨 — 인용 금지)은 원작이 아니라 Battle Brothers에 관한 주장이지만, 기각 주장 6건을 한곳에서 관리하려고 이 파일에 함께 둔다.
- 대장은 기각 주장 6건(R1-X1~X6)에 표결 결과만 남기고 근거 칸을 비워 두었다. 따라서 이 파일은 기각의 세부 사유를 추정하지 않는다. 쓰는 것은 표결 결과와, 확인 주장(R1-F*)의 검증 단서에 적힌 기각 기록뿐이다.
- 이 파일에서 R1-X* ID는 모두 "기각됨 — 인용 금지" 상태로만 언급한다. 근거로 쓰지 않는다.
- "대장의 관련 기록"과 2장 표의 "대장 기록" 칸은 주장 본문이 아니라 대장의 검증 기록(근거 칸)에서 온 것이다.

### 1.2 R1-X1 — Surgeon 손실 완충 규칙 (기각됨 — 인용 금지)

- **주장 내용**: Battle Brothers의 Blazing Deserts 확장에서 추가된 비전투 추종자 Surgeon이 쓰러진 캐릭터의 영구 부상 생존 확률을 크게 높이며, 이것이 사망과 생존 사이에 '영구 결손' 단계를 두는 손실 완충 규칙이라고 주장했다.
- **표결**: 3표 반박 검증 1-2로 기각.
- **대장의 관련 기록**: 확인 주장 R1-F9의 검증 단서에 "'Surgeon이 영구 결손 단계를 새로 도입하는 완충 규칙'이라는 별도 주장은 1-2로 기각"되었다고 적혀 있다 [R1-F9].
- **대신 인용할 것**:
  - Battle Brothers 개발진은 영구 부상을 커리어를 끝낼 수도, 흔적으로만 남을 수도 있는 양면적 결과로 설계했고, 남길지 내보낼지는 플레이어가 정한다 [R1-F9].
  - Surgeon은 Blazing Deserts DLC의 추종자(Retinue)이며, 쓰러진 대원이 사망 대신 영구 부상을 안고 살아남을 확률을 크게 높이는 것이 주 기능이다 [R2-C42]. 이 서술은 출시 전 개발 블로그 기준이다 [R2-C42].
  - 기본 규칙에서도 쓰러짐이 곧 사망은 아니고 확률 판정을 거친다 [R2-C14].
- (추론) 위 확인 주장을 쓸 때도 기각된 표현("Surgeon이 영구 결손 단계를 새로 만든다")으로 되돌아가지 않도록 문장을 고정한다. 손실 계층 설계는 [손실 계층](../03_value_and_loss/01_loss_tiers.md).

### 1.3 R1-X2 — 보스 처치 방식의 일반화 (기각됨 — 인용 금지)

- **주장 내용**: 원작의 보스 처치는 영웅 한 명의 직접 전투가 아니라 고유 특성과 고정 방어 시설의 결합으로 이뤄지며, 위치 탐색 특성과 저격 특성 보유자가 마나 대포를 여러 번 쏴야 성공한다고 주장했다.
- **표결**: 0-3으로 기각.
- **대장의 관련 기록**: 확인 주장 R1-F10의 검증 단서에 같은 일반화가 0-3으로 기각되었다고 적혀 있다 [R1-F10].
- **대신 인용할 것**: STAGE 0 한 장면으로서, 애쉬가 [지도 작성] 특성으로 여왕의 위치를 파악하고 데미안이 마나 대포로 여왕을 저격했다 [R1-F10]. 위치 파악 주체는 웹툰가이드 리뷰에서 데미안 쪽으로 서술되어 매체 간 차이 가능성이 있다 [R1-F10].
- (추론) 'STAGE 0에서 일어난 일'로만 인용하고 '원작의 보스 처치 방식'으로 일반화하지 않는다.

### 1.4 R1-X3 — '병력은 시간, 영웅은 결정타' 일반 구조 (기각됨 — 인용 금지)

- **주장 내용**: 원작 전투에서 일반 병력은 영웅의 결정타(궁극기 시전)에 필요한 시간을 버는 역할을 맡아 '병력 = 저지·시간 확보, 영웅 = 결정타'로 역할이 나뉘어 묘사되며, 특정 영웅의 궁극기 이름까지 들었다.
- **표결**: 0-3으로 기각.
- **대장의 관련 기록**: 표결 결과 외의 기각 기록은 대장에 없다.
- **대신 인용할 것**:
  - STAGE 0에서 루카스가 병사들을 지휘해 시간을 끌고 데미안이 마나 대포로 보스를 저격한 배치 [R1-F10] — 한 스테이지의 사례로만.
  - 일부 영웅(체인·캔들러·노바디·바이올렛 등)이 궁극기를 가진다는 사실 [R2-C87].
  - 대규모 방어전에 이름 없는 일반 병사도 참여해 희생된다는 사실 [R2-C88].
- (추론) STAGE 0 한 장면의 배치를 '원작 전투의 일반 역할 구조'로 넓히면 기각된 주장과 같은 문장이 된다. 기각 주장에만 나온 궁극기 이름도 쓰지 않는다.

### 1.5 R1-X4 — 성벽 방어전의 3중 방어 묘사 (기각됨 — 인용 금지)

- **주장 내용**: 원작 성벽 방어전에서 성벽의 다수 병력이 전방 영웅(루카스)을 지원하고, 보스(올롭)를 데미안이 연속 포격으로 격파하며, 적(시궁쥐 군단)이 성벽에 구멍을 내므로 3중 방어와 성벽 파손의 서사적 근거가 된다고 주장했다.
- **표결**: 1-2로 기각.
- **대장의 관련 기록**: 표결 결과 외의 기각 기록은 대장에 없다.
- **대신 인용할 것**:
  - 성벽이 파괴될 수 있다는 점: 가디스 블레싱 '무적의 성벽'(이번 전투 동안 성벽이 파괴되지 않음)이 있고, 대장은 원작 전장이 방위별 성벽·성벽 파괴 판정·적의 진입 방향을 규칙 단위로 다룬다고 정리한다 [R1-F12].
  - 네임드·병사·고정 포대가 한 전투에서 기능을 나눈 장면: STAGE 0 [R1-F10].
- (추론) '3중 방어의 원작 근거'가 필요하면 기각된 성벽 방어전 묘사가 아니라 STAGE 0 역할 분담 [R1-F10]과 스테이지 변수 [R1-F12]를 조합하고, 그 조합 자체는 "각색"으로 표기한다.

### 1.6 R1-X5 — 부활 횟수 제한 (기각됨 — 인용 금지)

- **주장 내용**: 원작에서 네임드 영웅을 영구히 잃을 수 있고(부상·사망·은퇴), 부활할 때마다 영혼이 약해져 한 번 더 죽으면 영원히 소멸하는 사례가 있어 '부활 횟수 제한 → 영구 결손' 규칙의 근거가 된다고 주장했다.
- **표결**: 0-3으로 기각.
- **대장의 관련 기록**: 확인 주장 R1-F11의 검증 단서에 원작의 '부활 횟수 제한 후 영구 소멸' 규칙 주장이 0-3으로 기각되었다고 적혀 있다 [R1-F11].
- **대신 인용할 것**: 결산창이 네임드 손실을 사망·부상(중상·경상)·실종으로 나눠 기록한다는 점, 중상이 장기 결손으로 이어진 릴리의 사례 [R1-F11].
- (추론) 부활 횟수 제한을 넣는다면 원작 근거 없는 각색으로 표기한다. 상세는 [지휘관 다운과 붕괴](../03_value_and_loss/03_commander_down_and_collapse.md).

### 1.7 R1-X6 — 적 3등급과 등급별 대응 주체 (기각됨 — 인용 금지)

- **주장 내용**: 원작 적(몬스터)이 일반·정예·보스급 3단계 등급으로 나뉘고, 이것이 적 등급별로 대응 주체(시설·용병·영웅)를 나누는 카운터 분담 규칙의 원작 근거가 된다고 주장했다.
- **표결**: 0-3으로 기각.
- **대장의 관련 기록**: 확인 주장 R1-F12의 검증 단서에 원작 적을 '일반/정예/보스 3등급'으로 나누는 주장이 0-3으로 기각되었다고 적혀 있다 [R1-F12].
- **대신 인용할 것**:
  - 다크 이벤트 '웅크리기'(물리 내성을 얻는 대신 느려지는 적 상태)가 피해 유형별 카운터 분담 규칙의 원작 근거다 [R1-F12].
  - 괴수에도 인간 가치 등급과 같은 표기(SSR 등)가 붙는다 [R2-C77].
- (추론) 괴수의 등급 표기를 '일반/정예/보스' 위협 계층으로 바꿔 읽으면 기각 주장과 같은 결론으로 미끄러진다. 적 등급 → 대응 축 규칙은 각색으로 표기하고, 상성 설계는 [적 상성 매트릭스](../01_rules_architecture/04_enemy_counter_matrix.md)에서 한다.

## 2. 원작에서 확인되지 않은 영역

| 영역 | 대장 기록 | 근거 ID | 기획서에서의 취급 |
|---|---|---|---|
| 피로도 | 원작에서 피로도에 관한 서술은 확인되지 않음 | [R1-F11] | 피로도 규칙은 전부 각색 |
| 적 등급별 대응 주체 | 3등급 분류 주장 기각, 확인되는 것은 피해 유형 내성(웅크리기) | [R1-F12] | 피해 유형 상성만 원작 근거, 등급→축 배정은 각색 |
| 성벽 내구도 수치 관리 | 원문에 내구도를 수치로 관리한다는 서술 없음, 파괴될 수 있다는 점만 확인 | [R1-F12] | 성벽 파괴 여부만 원작 근거, 내구도·수리 규칙은 각색 |
| '병력 = 시간 확보, 영웅 = 결정타' 일반 구조 | 일반화 주장 기각, STAGE 0 한 사례만 확인 | [R1-F10] | 슬롯 배치 사례로만 인용 |
| 보스 처치 방식 일반화 | 특성 조합·반복 포격 일반화 기각 | [R1-F10] | STAGE 0 한 사례로만 인용 |
| 부활 횟수 제한 | 기각 | [R1-F11] | 각색 |
| 돌발 이벤트의 일반 규칙 | 문서화된 사례 1건, 난입 적 약화의 일반화는 과장으로 판정 | [R2-C83] | 선례 1건으로만 인용 |
| 레벨 도달 → 궁극기 해금 | 명시 사례는 바이올렛 1명, 다른 멤버는 다른 능력 | [R2-C87] | 일반 규칙의 근거로 쓰지 않음 |
| 등급의 용병·영웅 설계 적용 | 설계 함의 문장은 판정에서 제외 | [R2-C77] | 각색 |
| '지휘관 패시브' 분류 | 분류명은 원문에 없고 패시브 이름만 있음 | [R2-C88] | 이 프로젝트의 분류명으로 표기 |
| '파티·부대 단위로만 편성' | 출처와 맞지 않음, 일반 병사도 참여해 희생 | [R2-C88] | 두 층 편성으로 인용 |
| 원작의 경영 요소 부재 | /스테이지 문서에 골드가 없을 뿐, 원작에는 도시경영 에피소드 등이 있음 | [R2-C83] | '원작에 경영 없음'으로 인용 금지 |
| 가디스 블레싱 비용·사용 개시 조건 | 업적점수 소모와 개시 조건은 나무위키에만 있음 | [R1-F12] | 2차 출처 단독임을 표기 |
| 애쉬의 '정찰' 분류 | 과장, 작전 지휘자이며 특성으로 위치만 파악 | [R1-F10] | '정찰 영웅'으로 인용 금지 |
| 다크 이벤트의 발동 방식 | 매 스테이지 무작위가 아니라 외부 개입 시 조건부 발동, 모든 스테이지에서 발동하지 않음 | [R1-F12], [R2-C82] | '매 스테이지 랜덤 변수'로 인용 금지 |

- (추론) 위 표의 네 영역(피로도, 적 등급별 대응 주체, 성벽 내구도 수치, 병력·영웅 역할 일반 구조)은 이 프로젝트의 3중 수성 구조에서 중심 규칙에 해당한다. 원작이 이 영역에 근거를 주지 않으므로, 이 규칙들은 벤치마크 게임의 확인 주장([게임 카드](../04_benchmarks/01_game_cards.md))을 근거로 설계하고 원작과는 "각색"으로만 연결한다.

## 3. 원작 인용 주의 규칙

> **[규칙 후보 SRC-23]** 원작 사실을 인용할 때는 출처가 2차 위키(나무위키 본 문서·하위 문서)임을 함께 표기하고, 독립 출처로 교차 확인되지 않은 항목은 그 사실을 밝힌다.
> - 근거: [R2-C77], [R1-F10], [R1-F12]
> - 트레이드오프: 독자가 원작 근거의 신뢰도를 스스로 판단할 수 있다 / 문장이 길어지고 원작 근거의 설득력이 약해 보인다.

> **[규칙 후보 SRC-24]** 웹툰과 소설에서 서술이 갈릴 수 있는 장면은 매체를 명시해 인용하고, 한 매체의 서술만으로 규칙의 원작 근거를 고정하지 않는다.
> - 근거: [R1-F10]
> - 트레이드오프: 매체 차이로 생기는 오인용을 막는다 / 매체별 확인 작업이 필요해 인용 비용이 늘고, 확인 전까지 해당 규칙의 원작 근거가 비어 있게 된다.

> **[규칙 후보 SRC-25]** 원작과 연결되는 기획 문장은 "원작 근거"(대장 ID 포함)와 "각색"(원작에 없거나 원작을 확장한 것)으로 나눠 표기한다.
> - 근거: [R1-F10], [R2-C77], [R2-C88]
> - 트레이드오프: 원작 팬 대상 소통과 내부 검토에서 무엇이 원작 그대로인지 분명해진다 / 표기 부담이 늘고, 각색 비중이 높게 드러나 '원작 재현' 마케팅 문구와 충돌할 수 있다.

> **[규칙 후보 SRC-26]** 원작에서 한 번만 기록된 사례(돌발 이벤트, 레벨 도달 궁극기 해금, 승급 퀘스트를 거친 등급 상승, STAGE 0 역할 분담)는 '선례 1건'으로만 인용하고 일반 규칙의 원작 근거로 쓰지 않는다.
> - 근거: [R2-C83], [R2-C87], [R1-F10]
> - 트레이드오프: 사례 1건을 원작 전체의 규칙으로 부풀리는 과장을 막는다 / 원작 근거로 내세울 수 있는 규칙의 수가 줄어든다.

> **[규칙 후보 SRC-27]** 부분 확인 주장은 대장의 수정 문장 범위만 인용하고, 수정 전 문장의 과장(등급 목록에서 R 누락, 같은 부대의 중복 계산 등)을 옮기지 않는다.
> - 근거: [R2-C87], [R2-C88]
> - 트레이드오프: 검증에서 걸러진 오류가 기획서로 되살아나지 않는다 / 인용할 때마다 수정 문장을 대조해야 한다.

> **[규칙 후보 SRC-28]** 기각 주장(R1-X*)의 내용은 원작 근거로도 각색의 출처로도 표기하지 않고, 같은 주제가 필요하면 1.1 대체 인용표의 확인 주장으로 바꿔 인용한다.
> - 근거: [R1-F9], [R1-F10], [R1-F11], [R1-F12]
> - 트레이드오프: 기각된 서술이 기획서에 남아 원작 근거처럼 굳는 일을 막는다 / 기각 주장에만 있던 구체 장면(예: 다른 스테이지의 성벽 방어전)을 기획 영감으로도 내세울 수 없다.

### 3.1 표기 예시

- 원작 근거: STAGE 0에서 릴리는 아티팩트가 있는 중앙 포대로 들어오는 유일한 입구를 몸으로 막았다 [R1-F10] (나무위키 /스테이지 기준).
- 각색: 병목 차단 슬롯에 배정된 영웅은 입구 단위로 적 진입을 막는다 (원작 STAGE 0 한 장면을 슬롯 규칙으로 확장 — [원작 치환](01_battlefield_to_rules.md) 2.2절, SRC-01).

### 3.2 인용 전 점검

1. 인용하려는 문장에 대장 ID가 붙어 있는가?
2. 그 ID가 R1-X*가 아닌가?
3. 부분 확인이면 수정 문장 범위 안인가?
4. 나무위키 단독 서술이면 그 사실을 표기했는가?
5. 웹툰·소설 중 어느 서술인지 갈릴 수 있는 장면인가?
6. 사례가 하나뿐인 묘사를 일반 규칙처럼 쓰지 않았는가?
7. 원작에 없는 부분을 "각색"으로 표기했는가?
