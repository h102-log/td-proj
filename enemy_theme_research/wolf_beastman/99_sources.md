# 출처와 검증 상태

이 폴더가 인용한 출처를 주제별로 모았다. 확인 방식은 [evidence/](evidence/) 노트 머리말과 본문 표기를 따랐다. 이미지 파일은 어느 조사도 내려받지 않았다.

확인 방식 범례

- **원문**: 페이지 본문을 직접 읽음(WebFetch, MediaWiki API 위키텍스트, curl, GitHub raw).
- **관찰**: 조사자가 브라우저로 그림을 직접 보고 적음. 사실이지만 눈으로 본 해석이 섞인다.
- **요약**: 본문을 못 열고 검색 결과 요약에서만 봄. 근거로는 약하다.
- **판매처**: 공식 자료가 아닌 판매 페이지 문구.
