# 4종 제안: 같은 머리, 다른 몸 하나

4종은 **같은 머리 꼴**(곧게 선 귀·짧고 굵은 주둥이·맨머리)과 **같은 꼬리·허리 가죽띠**로 한 씨족이 된다. 그 위에 종마다 정지 실루엣의 1차 특징을 하나만 크게 둔다. 바탕은 사용자 기본안(2026-10-29)이다. 연구가 바꾸자고 하는 곳은 «기본안과 다른 점»에 결정 번호(D1~D8, [README](README.md))로 표시했다. 털색은 팔레트 f24p hex만 쓰고, 램프는 `tools/art/wolf.py` 형식(안쪽 외곽선 | 음영 0~3)이다. 이 문서의 표 내용은 모두 [추론]이다. 근거 칸이 [사실]을 가리킨다.

## 공통 층: 머리 꼴이 «편»을 말한다

| 부위 | 제안 | 근거 |
|---|---|---|
| 귀 | 머리 폭 안에서 곧게 선 삼각 둘. 높이 2~3px, 사이 1px 이상. 안쪽 1px 밝은 털 | 45°에서 네 방향 모두 보이는 유일한 머리 부위. 고블린(옆)·코볼트(뒤)·오크(바깥 위)와 방향으로 갈림 ([03](03_pixel_readability.md)) |
| 주둥이 | 짧고 굵은 원통 + 검은 코끝 1px(`151a26`, 지금 `nose` 재질) | 코볼트는 길고 가는 주둥이(`kobold.py:42`) |
| 머리 | 맨머리. 투구 없음. 밤 늑대만 두건 | 장르가 머리를 드러낸다. 오크가 뿔 투구다 ([01](01_design_grammar.md)) |
| 목 | 밝은 털 갈기 톱니 1~2px. 알파만 크게 | 털 ↔ 비늘을 실루엣으로 가름 ([03](03_pixel_readability.md)) |
| 꼬리 | 굵고 끝이 밝음. 아래로 늘어지되 조금 옆으로 | N 단서. 다리와 뭉침 방지 ([03](03_pixel_readability.md)) |
| 허리 | 4종 공통 가죽띠, `36170c` \| `45230d` `45230d` `724113` `724113` | 4마리 무리·4종이 한 씨족으로 묶임 ([01](01_design_grammar.md) 야만 대 규율) |
| 숙임 | 오우거(6°, `ogre.py:20`)쯤까지. 고블린(12°)·코볼트(16°)보다 얕게 | 코볼트의 사선을 피함 (`kobold.py:20`) |
| 웅크림 | 도약 늑대·알파만 | «웅크림 = 곧 뛴다» 한 가족 ([04](04_role_variants.md)) |
| 그림 수 | 4종 모두 정지 1 + 걷기 2 + 공격 키 포즈 1 + 누움 1. 도약 늑대 + 웅크림 1(뜀 1 선택), 알파 + 웅크림 1 + 뜀 1 | 지금 네발 시안과 같은 구성(`wolf.py:4`) |
| 뼈대 | 사람형 공용 `rig()`(`hero.py:49` 이하)에 머리·꼬리·갈기 부품을 더함. 크기는 `scaled()` | 고블린·오크·코볼트가 같은 방식 |

## 늑대 — 무리로 오는 기준형

게임 역할 [사실]: 4마리씩 무리로 나오는 평범한 근접 적. 1웨이브에만 320마리다(`insights/2026-10-27_round2_wolf.md:58`, `:122`).

| 항목 | 제안 |
|---|---|
| 1차 특징 | 아무것도 더하지 않은 **곧은 기준형**. 넷이 똑같아 «무리»로 읽힌다 |
| 자세 | 직립, 숙임 얕게. 걷기는 윗몸 고정 1px 오르내림(기사 걷기 그대로) |
| 장비 | 가죽 흉갑(털보다 어두운 `45230d` 계열, 아군 병사 가죽 `70462a`보다 어둡게), 공통 허리띠, 오른손 **짧은 휜 칼**을 가슴 높이에 바깥으로 눕혀 듦 |
| 털 | `2a1d0d` \| `392a1c` `684c3c` `927e6a` `927e6a` (현행). 밝은 털 `392a1c` \| `927e6a` `a4aec2` `d0d6e0` `d0d6e0`(현행)을 주둥이·가슴·목 갈기에 **넓게** |
| 눈 | `151a26` 어두운 점 |
| 웅크림·뜀 | 없음 |
| 공격 키 포즈 | 칼 내려치기(기사 공격 자세 재사용) |
| 24px 근거 | 무기는 가슴 높이에 대비를 두라는 Valve 읽기 순서 ([MIGS08](https://cdn.fastly.steamstatic.com/apps/valve/2008/MIGS08_ConnectingVisualsToGameplay.pdf)). 기사 정지 자세는 검을 바깥으로 45° 눕혀 방향마다 검 끝이 몸 밖으로 3px 이상 나오게 했다(`hero.py:18-20`). 졸개는 수수하게(Gnoll Reaver, [04](04_role_variants.md)) |
| 기본안과 다른 점 | «짧은 칼»을 **휜** 칼로 좁힘. 털 유지 + 밝은 면적 키움(D8) |

| 위험 | 정도 | 갈리는 것 |
|---|---|---|
| 오크: 피부 램프가 같다(`orc.py:12` `684c3c` `927e6a`) | 중간 | 머리(뿔 투구 ↔ 선 귀), 철판·붉은 앞자락 없음, 1.1배 ↔ 1.0배, 넓은 칼 ↔ 짧은 휜 칼 |
| 흙 타일 `684c3c`와 털 중간 칸이 같다 | 중간 | 밝은 주둥이·가슴·갈기 면적, 어두운 가죽 흉갑 |
| 아군 병사: 가죽 조끼 + 검(`soldier.py:1`) | 낮음~중간 | 가죽 모자·방패 없음, 귀·주둥이·꼬리, 털. 칼이 휘었다 |
| 고블린: 몽둥이·옆 귀·큰 머리·0.8배 | 낮음 | 머리 비례, 귀 방향, 무기 꼴 |
| 원작: «브라운 = 일반병»과 하나 맞음 | 낮음 | 회색 털 종류를 두지 않아 세 단 사다리가 생기지 않음 ([02](02_source_work_mood.md)) |
| 칼이 짧아 몸에 묻힘 | 중간 | 바깥 45° 눕힘. 굽어 보고 날 길이를 정함 |

## 도약 늑대 — 무릎을 접은 낮은 용수철

게임 역할 [사실]: 성벽 앞에서 0.8초 웅크린 뒤 성벽 칸 위로 뛰어오른다. 그 칸의 아군을 1칸 밀치고 0.5초 기절시킨다. 뛴 뒤 3초 동안 느려진다(`insights/2026-10-27_round2_wolf.md:76-81`).

| 항목 | 제안 |
|---|---|
| 1차 특징 | **무릎·엉덩이를 깊게 접은 낮고 넓은 꼴**, 긴 다리. 걸어올 때부터 늑대와 갈린다 |
| 자세 | **몸통은 세운다**. 키는 무릎으로 줄이고 폭은 벌린 다리로 늘린다. 사선이 아니라 납작한 덩어리 |
| 장비 | 갑옷 없음(가벼운 차림), 다리 감개 `392a1c`, 공통 허리띠, **쌍단검을 역수로 낮게** 쥐어 날이 허리 옆·팔꿈치 뒤로 나옴 |
| 털 | `36170c` \| `724113` `a56243` `efb775` `efb775` (현행 황갈에서 한 단계 밝힘, 평균 101 → 143). 밝은 털 `724113` \| `a56243` `efd8a1` `efd8a1` `efd8a1` |
| 눈 | `151a26` |
| 웅크림·뜀 | 웅크림 1장: 무릎을 더 접고 두 날을 뒤로 젖힘. **귀는 세우고 갈기를 보인다**. 뜀 1장은 선택(공중에서 두 다리를 뒤로) |
| 공격 키 포즈 | 한 손 찌르기(오른손 앞, 왼손 뒤). 좌우 비대칭 |
| 24px 근거 | 정지 실루엣이 1차 특징이어야 한다(Riot, [04](04_role_variants.md)). 덮치는 적은 약 1초 낮게 웅크려 예고한다(L4D Hunter). 밤에는 명도가 남는다(`06_readability.md:32`) |
| 기본안과 다른 점 | «숙인 자세» → 무릎 접기(D1). 털 한 단계 밝게(D2). 쌍단검은 유지하되 쥐는 법을 정함 |

| 위험 | 정도 | 갈리는 것 |
|---|---|---|
| 코볼트: 16° 사선 + 앞으로 든 두 팔 + 두 팔 할퀴기, 둘 다 성벽에 오름(`kobold.py:20-25`) | 기본안대로면 **높음**, 제안대로면 중간 | 몸통 세움, 날은 앞이 아닌 옆·뒤, 한 손 찌르기, 밝은 모래색(명도 143 ↔ 코볼트 75), 선 귀·갈기 |
| 오우거 피부 밝은 칸 `a56243`과 같은 색 | 낮음 | 1.0배 ↔ 1.7배, 몽둥이 없음 |
| 아군 방패병(원 노트의 팔방패 안을 쓰면) | 해당 없음 | 쌍단검을 유지하므로 생기지 않음 ([04](04_role_variants.md)) |
| 두 단검이 2~3px라 몸에 묻힘 | 중간 | 날을 몸 실루엣 밖으로 빼는 쥐는 법. 묻히면 다리 꼴이 1차 특징을 맡는다 |
| 원작 | 낮음 | 원작 텍스트에 도약형 늑대 묘사가 없다 |

## 밤 늑대 — 두건 그늘 속 두 점

게임 역할 [사실]: 어둠에 이동·공격이 빨라지고, 물면 4초 동안 초당 2의 출혈을 건다. 어둠 속 불빛 밖에서는 눈빛 두 점만 보인다(S240, `SPEC.md:469`, I193 ④ `:762`). 몸 크기 1.12배(`wolf.py:18`).

| 항목 | 제안 |
|---|---|
| 1차 특징 | **귀를 덮는 뾰족 두건 + 아래로 퍼지는 망토 = 삼각 실루엣** |
| 자세 | 직립, 고개를 조금 숙여 두건 그늘을 만든다. 주둥이 끝만 두건 밖으로 |
| 장비 | 검은 두건·망토 `151a26` \| `151a26` `262d3d` `262d3d` `3a4357`(털보다 조금 어둡게, 망토는 `flare()`), 공통 허리띠, 왼손 **짧은 낫** 하나 |
| 털 | `151a26` \| `151a26` `262d3d` `3a4357` `56607a` (맨 위 칸을 `3a4357` → `56607a`로 올려 윗면 테) |
| 눈 | `efd8a1`. 낮에도 두건 그늘 속 밝은 두 점으로 그린다 |
| 웅크림·뜀 | 없음 |
| 공격 키 포즈 | **물기**: 고개를 내밀고 턱을 벌림. 낫 든 손은 옆으로 |
| 24px 근거 | 은신형은 두건·망토로 머리 윤곽을 지우고 그늘 속에 빛나는 점을 남긴다(Gutter Runner·Hunter, [04](04_role_variants.md)). 낮 눈 `efd8a1`(명도 217)과 밤 점 `f0e060`(214)이 같은 값이라 이어진다. 낮 풀(71)보다 털 맨 위 칸(96)이 밝아야 테가 남는다([03](03_pixel_readability.md)) |
| 기본안과 다른 점 | 발톱 → 짧은 낫 + 물기(D3). 두건은 귀를 덮음(D4). 털 맨 위 칸 한 단계 |

| 위험 | 정도 | 갈리는 것 |
|---|---|---|
| 코볼트: 맨손 발톱(기본안) | 기본안대로면 **높음**, 제안대로면 낮음 | 낫 하나, 물기 공격, 두건 삼각 |
| 아군 궁수: 두건(`archer.py:1`, 회갈 두건 `archer.py:14`) | 중간 | 궁수는 성벽 위·활·화살통·따뜻한 회갈. 밤 늑대는 땅·검정·주둥이·꼬리 끝(망토 밑) |
| 코볼트·오우거 허리천 남색 `151a26` `262d3d` `3a4357`(`kobold.py:13`, `ogre.py:13`) | 낮음 | 망토 면적과 꼴 |
| 낮 풀밭에서 털 중간 칸이 풀과 같은 값 | 중간 | 윗면 테 `56607a`, 밝은 눈, 어두운 외곽선 |
| 원작: 밤·보름달 | 낮음 | 장르 공통([01](01_design_grammar.md)). 이름에 «만월»을 쓰지 않는다 |
| 원작: 발톱 장갑 안(D3 B)을 고르면 수인 격투 장갑 연상 | 중간 | 그래서 낫(D3 A)을 권함 |

## 알파 늑대 — 목을 두른 흰 덩어리

게임 역할 [사실]: 보스. 성벽 위 원거리 유닛을 1초 웅크림 뒤 0.4초 뛰어 덮치고, 누르고 문다. 둘레 4칸의 늑대들을 30% 빠르게 하는 울부짖음 오라가 있다(`insights/2026-10-27_round2_wolf.md:101-102`). 어둠 속에서는 몸 대신 덮치기 예고가 보인다(`battle_view.gd:295-298`).

| 항목 | 제안 |
|---|---|
| 1차 특징 | **1.8배 + 목·어깨를 두른 흰 갈기 덩어리**. 갈기는 목·어깨에서 멈춘다(등까지 덮으면 안장 무늬, `wolf.py:107`) |
| 자세 | 직립, 어깨 넓게. 숙임 얕게 |
| 장비 | **어두운 철 흉갑** `151a26` \| `151a26` `262d3d` `3a4357` `3a4357`(어깨판 없음, 어깨는 갈기가 덮음), 공통 허리띠, 오른손 **큰 도끼**(한 손), 왼손은 비워 누르기에 씀 |
| 털 | `2a1d0d` \| `392a1c` `392a1c` `684c3c` `927e6a` (늑대 계열, 한 단계 어둡게). 갈기 `56607a` \| `a4aec2` `d0d6e0` `d0d6e0` `d0d6e0`(현행). 흉터 `efb775` 한 줄(현행 `wolf.py:120`처럼 얼굴 한쪽 세로) |
| 눈 | `ef3a0c` 붉은 눈 |
| 웅크림·뜀 | 웅크림 1장(낮추고 왼손을 앞으로, 도끼는 뒤로), 뜀 1장(왼손·주둥이가 앞, 턱 벌림) |
| 공격 키 포즈 | 도끼 내려찍기. 덮친 뒤 누르기·물기 그림은 웅크림·공격 키 포즈 재사용과 한 장 더 굽기 가운데 굽어 보고 정한다 |
| 24px 근거 | 우두머리는 크기 + 목둘레 덩어리(Gnawer·Great Jagras·짐승인간 뿔, [04](04_role_variants.md)). 24px에서 확실히 남는 등급 신호는 몸집·흰 덩어리·빛나는 점([01](01_design_grammar.md)). «어두운 철 · 중간 털 · 밝은 갈기» 세 명도 칸 |
| 기본안과 다른 점 | 털을 잿빛 → 짙은 회갈(D5). 철판을 털보다 어둡게(D5). 눈 `efac28` → `ef3a0c`(D6). 흰 갈기 유지(D7). 도끼는 한 손 |

| 위험 | 정도 | 갈리는 것 |
|---|---|---|
| 오우거: 1.7배 보스 + 큰 몽둥이(`ogre.py:1`, `:18`) | 중간 | 흰 갈기 고리, 선 귀, 도끼 머리의 한쪽 날, 털 ↔ 작은 머리·불룩 배·붉은 갈색 피부. 둘은 라운드가 다르다(2라운드 ↔ 3~6라운드) |
| 오크: 철판 | 낮음 | 어깨판·뿔 투구 없음, 1.8배 ↔ 1.1배 |
| 현행 잿빛 털 `3a4357` `56607a` = 고블린 피부·오크 철 램프(`goblin.py:14`, `orc.py:13`) | 현행대로면 중간 | D5 A로 털을 따뜻하게 옮기면 사라짐 |
| 현행 눈 `efac28` = 고블린·코볼트 눈(`goblin.py:17`, `kobold.py:14`) | 현행대로면 낮음~중간 | D6 A |
| 원작: 흰 갈기 ≈ «화이트 웨어울프 = 상위 정예» | 낮음~중간 | 흰·은빛 우두머리는 장르 공통(Tovolar·Whitefur Howler·Wolf Sentinel). 회색 종류를 두지 않음. «늑대왕»·«군단장» 같은 호칭을 쓰지 않음 |
| 흉터가 1~2px라 안 보임 | 낮음 | 3차 특징이라 안 보여도 1차가 남음 |

| 늑대 | 귀, 밝은 가슴·주둥이, 칼 끝 | 주둥이 3~4px, 가슴 높이 칼, 꼬리 | 귀, 갈기 톱니, 꼬리 끝, 칼 끝 |

한 손 무기·낫·도끼는 좌우가 비대칭이라 바라보는 방향도 알려 준다(Riot, [04](04_role_variants.md)). 4방향을 다 굽고 반전은 쓰지 않으므로 그대로 된다.

## 남은 위험

- 이 제안은 굽어 본 결과가 아니다. 귀 2~3px, 갈기 1~2px, 날 길이는 추정이다. 굽어서 확대본·실제 크기·회색조·불빛 가장자리에서 본다.
- 웹툰 속 늑대인간을 보지 못했다. 사용자가 본 화의 그림이 이 제안과 닮았는지는 그 화를 봐야 안다([02](02_source_work_mood.md)).
- 사람형 `rig()`에 꼬리·갈기·턱(물기)·두건을 더하는 것은 처음이다. 걷기 윗몸 고정 검사(lint H3)에 꼬리를 «몸통» 부위로 둘지 굽기 때 정한다(코볼트는 꼬리를 `torso`로 둠, `kobold.py:40`).
