# 귀·갈기·자세가 늑대 수인 4종을 가른다

작성 2026-10-29. 질문: 무장한 늑대 수인(늑대 머리 사람형 전사) 적 컨셉을 조사해, 2라운드 늑대 4종(늑대·도약 늑대·밤 늑대·알파 늑대)을 24px 도트(45° 위, S·E·N·W 4방향, 코드로 만든 3D 형체를 굽는 방식)로 다시 그릴 근거와 4종 디자인 제안을 낸다. 원작 «내가 디펜스 게임의 폭군이 되었다»는 분위기만 참고하고 디자인·이름·문양은 옮기지 않는다.

표기: **[사실]** 출처가 있는 것(웹 출처는 링크, 프로젝트 근거는 `파일:줄`). **[추론]** Claude 판단. **[계산]** 팔레트 hex를 Rec.601 명도 Y(0~255)로 바꾼 값. 원 노트는 [evidence/](evidence/)에 그대로 있다.

## 결론

1. [추론] 장르에서 무기를 쥔 늑대 수인은 «씨족·군대의 무사»로 읽히고, 맨손 발톱 늑대인간은 «저주받은 짐승»으로 읽힌다. 사용자 기본안(가죽 갑옷+짧은 칼, 쌍단검, 두건, 철 갑옷+큰 도끼)은 무사 쪽 문법에 맞는다 ([01](01_design_grammar.md)).
2. [추론] 4종 공통 표지는 **곧게 선 삼각 귀 둘 + 목 갈기 톱니 + 굵고 끝이 밝은 꼬리**다. 45° 위 카메라에서 네 방향 모두 보이는 머리 부위는 귀뿐이다. 그래서 투구를 씌우지 않는다 ([03](03_pixel_readability.md)).
3. [추론] 종마다 정지 실루엣의 1차 특징을 **하나만** 크게 둔다. 늑대=곧은 기준형+가슴 높이 짧은 휜 칼, 도약 늑대=무릎을 접은 낮고 넓은 꼴, 밤 늑대=귀를 덮는 뾰족 두건+망토, 알파=1.8배+목·어깨를 두른 흰 갈기 ([04](04_role_variants.md), [05](05_proposal.md)).
4. [사실·계산] 기본안을 그대로 굽으면 겹치는 곳이 있다. 도약 늑대 «숙인 자세»는 코볼트의 16° 사선과, 밤 늑대 맨발톱은 코볼트 맨손 발톱과 겹친다. 알파 눈 `efac28`은 코볼트·고블린 눈과 같고, 알파 잿빛 털 `3a4357`·`56607a`는 고블린 피부와 오크 철 램프에 든다. 늑대 털 `684c3c`·`927e6a`는 흙 타일·오크 피부와 같다. 늑대와 도약 늑대의 털 명도는 97 대 101이라 회색조에서 갈리지 않는다.
5. [추론] 고칠 안은 이렇다. 도약 늑대는 무릎으로 낮추고 털을 한 단계 밝힌다. 밤 늑대는 맨발톱 대신 짧은 낫을 들고 물기로 친다. 알파는 털을 늑대 계열 짙은 회갈로, 철판을 털보다 어둡게, 눈을 `ef3a0c`로 바꾼다. 늑대는 털을 유지하고 밝은 면적을 키운다. 모두 사용자 결정 거리다(아래 표).
6. [사실] 원작을 다룬 나무위키 문서 다섯에서 늑대인간의 무기·갑옷 묘사를 찾지 못했다. 수인의 무술은 맨주먹 권법이다. **한국어 웹툰 속 늑대인간 그림은 보지 못했다.** 네이버가 막혔고, 영어판 무료분(1~23화, 2026-10-29 목록에서 확인. 23화는 호수 왕국 던전)은 늑대가 나오기 전이다. 그래서 «원작과 닮지 않았다»는 텍스트 기준으로만 말할 수 있다 ([02](02_source_work_mood.md)).
7. [추론] 알파의 흰 갈기는 원작 «화이트 웨어울프 = 상위 정예»와 읽힘이 닮았다. 그러나 흰·은빛 우두머리는 장르 공통이다. 4종에 «갈색 → 회색 → 흰색» 등급 사다리만 만들지 않으면 위험은 낮다.

## 4종 제안 요약

털색은 팔레트 f24p hex만 쓴다. 램프 순서는 `wolf.py` 형식(안쪽 외곽선 | 음영 0~3)이다. 자세한 근거와 위험은 [05](05_proposal.md).

| 종류 | 1차 특징(정지 실루엣) | 자세 | 장비 | 털 램프 | 눈 | 웅크림·뜀 |
|---|---|---|---|---|---|---|
| 늑대 | 곧은 기준형. 4마리가 똑같다 | 직립, 숙임은 고블린(12°)보다 얕게 | 가죽 흉갑·허리띠, 오른손 짧은 휜 칼을 가슴 높이에 | `2a1d0d` \| `392a1c` `684c3c` `927e6a` `927e6a` (현행 유지), 주둥이·가슴·목 갈기 `a4aec2` `d0d6e0` 면적을 키움 | `151a26` | 없음 |
| 도약 늑대 | 무릎·엉덩이를 깊게 접은 낮고 넓은 꼴, 긴 다리 | 몸통은 세운다(코볼트 사선 피함) | 갑옷 없음, 다리 감개, 쌍단검을 역수로 낮게 쥠 | `36170c` \| `724113` `a56243` `efb775` `efb775`, 밝은 털 `efd8a1` | `151a26` | 웅크림 1장(0.8초). 뜀은 선택 |

## 사용자 결정이 필요한 것

기본안(사용자 2026-10-29)과 다른 점만 적었다. «권장»은 Claude 안이다.

| 번호 | 무엇 | 선택지 | 권장과 까닭 |
|---|---|---|---|
| D1 | 도약 늑대의 «낮은 자세»를 어떻게 만드나 | A 무릎·엉덩이 접기 / B 몸통 숙임(기본안 문구) | **A**. 숙임은 코볼트의 «앞으로 16° 기운 사선 + 앞으로 든 두 팔»과 겹친다(`tools/art/kobold.py:20-21`). 둘 다 성벽에 오르는 적이라 꼴이 닮으면 같은 규칙으로 오해한다 |
| D2 | 도약 늑대 털 명도 | A 한 단계 밝힘(평균 143) / B 현행 황갈(101) | **A**. 현행은 늑대(97)와 회색조에서 같다. 밤에는 색보다 명도가 남는다 |
| D3 | 밤 늑대의 «발톱(출혈)» | A 짧은 낫 + 물기 공격 / B 쇠 덧댄 발톱 장갑 / C 맨발톱(기본안) | **A**. C는 코볼트 맨손 발톱과 겹친다. B는 «무장»으로 읽히지만 원작 수인의 격투 장갑을 떠올리게 할 수 있다. 출혈은 이미 맞은 아군 몸의 핏방울로 보인다(SPEC I193 ③) |
| D4 | 밤 늑대 두건이 귀를 덮나 | A 귀를 덮는 뾰족 두건 / B 귀 구멍 난 두건 | **A**. 머리 윤곽이 «귀 둘»에서 «뾰족 하나»로 바뀌는 것이 1차 특징이 된다. 진영 표지는 주둥이·꼬리가 맡는다 |
| D5 | 알파 털과 철 갑옷 | A 털을 늑대 계열 짙은 회갈로, 철판은 털보다 어둡게 / B 잿빛 털 유지, 철 면적을 가슴판 하나로 줄임 | **A**. 현행 잿빛 털은 오크 철 램프·고블린 피부와 같은 칸이라 철 갑옷과 한 덩어리가 된다. 회색 계열을 빼면 원작식 «회색 정예 → 흰색 상위» 연상도 준다 |
| D6 | 알파 눈 | A `ef3a0c` 붉은 눈 / B `efd8a1` / C `efac28`(현행) | **A**. `efac28`은 고블린·코볼트 눈(`goblin.py:17`, `kobold.py:14`)이다. B는 밤 늑대 눈과 겹친다. 붉은 눈은 «강화된 개체» 관례다 |
| D7 | 알파 흰 갈기 | A 유지 / B 은회 `a4aec2` 위주로 낮춤 | **A**. 24px에서 가장 확실한 우두머리 신호다. 원작 닮음은 등급 사다리를 안 만들면 낮다 |
| D8 | 늑대 회갈 털(`684c3c`=흙 타일·오크 피부) | A 털 유지 + 밝은 주둥이·가슴·목 갈기 면적 키움 / B 다른 색으로 옮김 | **A**. 팔레트에 남은 갈색은 도약 늑대·오우거와 부딪친다. 오크와는 머리 꼴(뿔 투구 ↔ 선 귀)로 갈린다 |

확인 질문 하나: 사용자가 «웹툰처럼 무장한 수인»을 본 화가 몇 화인가. 그 화의 시각 요소를 피할 목록에 더해야 한다. 추정 범위는 2부 후반(대략 170~195화)이지만 근거가 약하다([02](02_source_work_mood.md)).

## 이번 조사로 바로잡는 것

- [사실] 밤 늑대 눈빛 두 점은 **이미 정해져 구현됐다.** [evidence/role_variants.md](evidence/role_variants.md) 4장·5장은 «S213 예외는 사용자 확인 전»이라 적었는데 틀렸다. 사용자 2026-10-27 «1번 ㅇㅇ»로 정했고, SPEC S240(`SPEC.md:469`)·I193 ④(`SPEC.md:762`)·EV564(`EVAL.md:574`)에 들었다. 게임은 숨은 밤 늑대 자리에 밝은 노랑 `f0e060` 점 둘을 2px 간격으로 찍는다(`src/ui/battle_view.gd:23`, `:425-428`).
- [사실] 설계 문서의 «사람형 늑대(늑대인간)도 만들지 않는다»(`insights/2026-10-27_round2_wolf.md:145`)는 사용자 2026-10-29 결정(«동물이 아니라 무장한 수인»)으로 무효가 됐다. 이 줄과 3.7 그림 표(`:135-143`)는 고쳐야 한다. 지금 `tools/art/wolf.py`(커밋 전)는 네발 뼈대라 사람형으로 바꿀 때 갈아엎는다(`wolf.py:1-4`).
