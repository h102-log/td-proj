# 05. 원작의 스테이지별 적 짜임 (Q5)

《디펜스 게임의 폭군이 되었다》에서 스테이지마다 어떤 군단이 오고, 어떤 기믹·약점이 있었는지 정리한다. **원작의 이름·문구·고유 디자인은 우리 게임에 쓰지 않는다.** 같은 원작의 공식 도트 게임이 개발 중이다(`source_mood_research/README.md` «우리 게임에 대한 핵심 제안» 5). 여기서는 문법만 뽑는다. 아래 원작 이름은 근거를 짚으려고만 적었다.

- 출처는 모두 나무위키(2차, 소설 기준)의 검색 요약이거나, 지난 조사가 웹툰을 직접 본 기록이다. 원문 페이지는 열지 못했다(README «조사 방법»).
- 지난 조사에 있는 것은 «[기존]»으로 표시했다. 1년차 스테이지 표는 `source_mood_research/01_work_and_world.md` §4.2, 다크 이벤트 5종의 효과는 `game_design_research/05_source_work_translation/01_battlefield_to_rules.md` §4에 있다.

## 2. 미확인과 기각

- STAGE 0 여왕을 «다섯 번째 포격»에 잡았다는 검색 요약은 지난 조사의 기각(R1-X2, `01_battlefield_to_rules.md` §2.3)과 부딪친다. 웹툰 7화 관찰은 «포탄이 여왕 이마에 맞는다»였다. 미확인으로 둔다 [C-09].
- «해가 지면 거미가 잠든다»는 텍스트 출처로는 찾지 못했다. 소설 2권 사본 요약의 «잠든 듯, 공격하면 반드시 반응한다»는 STAGE 0 뒤의 다른 장면이다 [C-07].
- 레벨 수치는 웹툰과 나무위키가 반대로 적는다(지난 조사 01 §4.3). 이 표에서는 레벨을 뺐다.

## 3. 문법으로 뽑으면 (모두 추론)

1. **한 판 = 한 군단.** 보상 화폐까지 군단 이름을 단다 [C-01]. 사용자의 «1라운드 슬라임, 2라운드 울프» 생각과 같은 짜임이다. 섞임은 예외이고, 섞일 때는 둘 중 하나다. ① 지휘층과 물량층의 종이 다르다(흡혈귀 + 구울) [C-04]. ② 다른 군단이 사건으로 끼어든다(난입) [C-06].
2. **군단 안은 «한 축만 다른» 2~5종이다.** 축은 역할·재질·원소·크기·털색이다 [C-03]. 우리 «일반 적 1종·변종 1~2종·보스» 틀과 수가 맞는다. 정예는 2~4%로 적다 [C-02].
3. **물량은 개체 무게와 반대로 간다.** 쥐 3,251 → 거미 1,108 → 리빙아머 1,052 → 흡혈귀 1,005 → 와이번 743 → 가고일 602 → 스켈레톤 506 → 샐러맨더 420 → 골렘 260 → 거대 존재 1이다. 단단한 테마일수록 수가 적다. 우리 웨이브 표가 테마마다 수를 다르게 잡을 근거다.
4. **기믹이 요구한 대응은 거의 «방어의 다른 곳»이다.**
   - 숨은 보스 → 정보 역할과 결정타 역할의 짝(STAGE 0)
   - 시간 버티기(해 질 녘) → 섬멸이 아니라 지연(STAGE 0)
   - 두 곳 지키기 → 병력 쪼개기(STAGE 3)
   - 재질 약점(은) → 맞는 피해 유형을 들고 가기(STAGE 5)
   - 핵 약점 → 보스의 특정 부위(STAGE 1)
   - 물량 → 광역·도발(STAGE 2), 다크 이벤트 «번식»(STAGE 15)
   - 준비 시간 단축 → 미리 지어 두기(STAGE 6)
   - 양동·저주 → 본진을 비우는 위험(STAGE 10)
   - 난입 → 계획에 없던 군단(STAGE 9)
   부록 A의 «라운드마다 방어의 다른 약점을 노린다»는 원칙과 같은 방향이다.
5. **낮밤은 원작에서 약하다.** 확인된 것은 «해 질 녘이 버티기의 끝»(웹툰) 하나다. 밤 수성전, 밤에 강해지는 적은 찾지 못했다 [C-07][C-08]. 그래서 우리 게임의 «밤에는 불빛 밖이 어둡다»(S210·S211)는 원작에서 가져온 것이 아니라 새로 얹은 축이다. 원작 문법에 맞추려면 «밤에 강해지는 적»보다 «해 질 녘까지 버티기»나 «밤에 잠드는 적»(우리 쪽에서는 낮밤 반대) 쪽이 가깝다.
6. **어둠 속 떼의 그림.** 웹툰은 어둠 속 떼를 붉은 «눈 점»으로, 리빙아머 행렬을 «푸른 불 점»으로 그린다 [기존, C-16]. 테마마다 적 강조색 하나(원작 무드보드)와 밤 가독성([06](06_readability.md))을 함께 풀 단서다.

## 4. 이름이 겹치는 것에 대해

원작에는 슬라임 군단(우두머리 포함)·늑대인간 군단·와이번 군단·스켈레톤 군단이 있다 [C-01][C-10]. 슬라임·늑대·와이번·해골은 판타지 일반의 몬스터라 테마로 쓰는 것만으로 원작을 옮기는 것은 아니다(추론). 다만 원작 고유의 이름(우두머리 이름·군단장 이명)·정보창 꼴(«○○ 군단 마석»)은 피해야 한다. 이 판단은 법적 검토가 아니라 지난 조사의 원칙을 따른 것이다.
