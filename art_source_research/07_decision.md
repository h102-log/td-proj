## 2. 권장안 — 에셋팩 A: Minifantasy, 아트는 팩만 쓰고 Claude는 코드에만

**내용:** Minifantasy Complete Bundle($69.99)을 산다. 게임에 실리는 아트는 팩 에셋만 쓴다. Claude는 게임 코드와 Godot 런타임 연출(셰이더·파티클 설정)을 맡는다. 폰트는 OFL 도트 폰트(물마루 또는 Galmuri), 캡슐은 개발자가 팩 아트로 합성한다.

**근거**

1. 출시 범위 대부분을 한 작가 화풍으로 채운다 [X-14] [A-37] (보충 조사, 별도 검증 없음). Claude가 가장 약한 인간형 유닛과 그 동작을 팩이 맡는다 [Q-22]. 건설 중·파손 상태도 건물 6종에 있다 [X-04] (보충 조사, 별도 검증 없음).
2. 일정: Claude 단독은 중앙값 35~40시간 추정이라 한 주 38시간과 4.2 제품 기능을 함께 담기 어렵다 [Q-25] [Q-27] (추론). 팩은 적용 작업이 중심이다(추론).
3. 스팀 AI 공개가 필요 없을 가능성이 높다 [P-05] [X-22] (보충 조사, 별도 검증 없음). AI 공개작은 리뷰 수가 약 52.6% 적다는 분석이 있다. 상관관계다 [X-15] (보충 조사, 별도 검증 없음).
4. 사용량 한도(WBS R6)에 아트 부담을 얹지 않는다(추론).
5. WBS R1("직접 그리는 아트는 이 일정에 넣지 않는다")·2.14("에셋팩 선택")와 맞는다.

**대가와 남은 확인**

- 8px 타일이라 해상도·격자를 다시 정해야 한다. 320×180/8px이면 칸 수는 그대로지만 한글 UI와 테스트 상수 `CELL_PX`에 영향이 있다. 640×360에 2배로 얹으면 칸 16px를 유지한다 [A-10]. 자세한 내용은 [05 §2](05_asset_packs_and_hybrid.md#해상도격자-영향).
- 시트의 실제 프레임 수는 확인 불가다. GIF 측정치뿐이다 [X-02] (보충 조사, 별도 검증 없음).
- 타워 공격·투사체, 성벽·타워 파손 상태는 확인 불가다 [X-07] [X-08] [X-09] (보충 조사, 별도 검증 없음).
- 크레딧 표기와 완성작 링크 전달 의무가 있다 [A-02].
- 캡슐에 팩 아트를 쓰는 것이 허용되는지 작가에게 물어야 한다(추론).

**빈 곳을 채우는 방법 (추론)**

- 투사체: Magic Weapons And Effects의 Shot 이펙트로 대신할 수 있는지 먼저 본다 [X-09] (보충 조사, 별도 검증 없음).
- 파손 표시: Godot `modulate`로 어둡게 하고, 텍스처 없는 GPUParticles2D로 연기를 낸다 [T-16]. 게임 코드로 처리하는 연출이다. Valve가 이것을 AI 콘텐츠로 보는지는 확인하지 못했다.
- 이것으로 부족해 Claude가 오버레이를 그리면 하이브리드가 된다. 그러면 AI 공개를 전제로 다시 판단한다 [A-36].

**뒤집히는 조건**

- Minifantasy 한 팩(True Heroes $5.99)을 사서 시트를 열었는데 다음 중 하나면 → 예비안으로 간다.
  - 걷기가 4프레임 미만이거나 4방향이 아니다.
  - 사용자가 화풍이 다크 판타지와 맞지 않는다고 판단한다.
- 해상도 선택지 두 개(320×180/8px, 640×360에 2배) 모두 받아들일 수 없다 → 예비안.
- 반나절 시험이 모든 기준을 통과하고, 사용자가 AI 공개를 받아들인다 → 하이브리드(Minifantasy + Claude 보충)나 Claude 단독을 다시 검토한다(§4).

## 3. 예비안 — 에셋팩 B: Ninja Adventure + Claude 보충 하이브리드

**내용:** 유닛·타일·UI·이펙트는 Ninja Adventure(CC0)를 쓴다. Claude는 다크 톤 팔레트 변환과 시설(거점·타워 3·성벽·생산 시설, 건설 중·파손)을 코드로 만든다. 폰트는 Galmuri11 또는 물마루(12px).

**근거**

1. CC0라 라이선스 위험과 비용이 없다 [A-12].
2. 16px라 SPEC U8 기본값(640×360, 칸 16px)과 테스트 상수를 그대로 쓴다(추론). Godot 4 예제가 있다 [A-12].
3. Claude는 비교적 잘하는 영역(기하 형태의 시설, 팔레트 교체)만 맡는다 [Q-22]. 가장 약한 인간형 유닛은 팩이 맡는다.
4. Minifantasy가 실패하는 이유(프레임 수, 8px 해상도)에 영향받지 않는다(추론).

**대가**

- AI 공개가 필요하다 [P-05] [A-36]. 리뷰 페널티 위험을 진다 [X-15] (보충 조사, 별도 검증 없음).
- 귀여운 화풍을 팔레트 변환으로 얼마나 다크 판타지에 가깝게 만들 수 있는지는 확인하지 않았다(추론).
- 시설 제작 시간이 든다. 추정 1.6~6.4시간 [Q-25].
- Claude가 만든 시설이 팩 화풍과 어울리는지는 미확인이다(추론).

**뒤집히는 조건**

- 반나절 시험의 타일 부분이 불합격이다 → Claude가 기하 자산도 안정적으로 못 만든다는 신호다. 시설을 갖춘 다른 16px 팩을 찾는 추가 조사가 필요하다. 이번 조사에서 시설이 풍부한 대안(Tiny Swords)은 64px 격자라 뺐다 [A-40].
- 팔레트 변환 결과를 사용자가 다크 판타지로 받아들이지 않는다 → 같은 조치.

## 4. 사용자 1안(Claude 단독)에 대해

배경의 방향은 "Claude가 만드는 쪽을 1안"이다. 이 보고서는 그것을 권장하지 않는다. 이유는 셋이다.

1. 품질: 출시 범위에서 가장 많은 인간형 유닛과 동작이 Claude가 가장 약한 영역이다 [Q-22] [Q-13]. 같은 방식으로 출시한 선례가 없다 [Q-17].
2. 일정: 중앙값 추정만으로 한 주 38시간이 찬다 [Q-25]. 같은 주에 4.2가 있다([WBS.md](../WBS.md) 4장).
3. 공개: AI 공개가 필요하고 [P-05], 공개작은 리뷰가 적다는 상관 분석이 있다 [X-15] (보충 조사, 별도 검증 없음).

Claude 단독을 고를 수 있는 조건(모두 필요, 추론):

- [08 반나절 시험](08_half_day_trial.md)이 모든 기준을 통과한다.
- [Q-27]의 다섯 조건을 지킨다. 특히 파이프라인을 11/02 전에 완성하고 유닛은 한 방향 + 반전으로 한다.
- 사용자가 AI 공개와 그 리뷰 위험을 받아들인다.
- 사용자가 WBS R1·2.14를 고친다(§5).
- 11/04 중간 점검에서 유닛 절반을 못 끝내면 유닛은 에셋팩으로 바꾼다 [Q-27].

## 6. 10/18까지 할 일 (제안)

1. Minifantasy True Heroes($5.99)를 사서 시트의 프레임 수·4방향 구조를 잰다 [A-09]. 반나절 시험의 비교 기준 이미지로도 쓴다.
2. [08 반나절 시험](08_half_day_trial.md)을 한다. 사용자 1안이 살아남는지를 가른다.
3. Minifantasy 작가에게 묻는다: 타워 공격·투사체, 성벽 파손 상태, 캡슐 사용 허용.
4. 해상도 선택지(320×180/8px 또는 640×360에 2배)를 정한다.
5. 10/18에 결정하고 `CREDITS.md` 첫 항목을 쓴다(WBS 2.14).

```
반나절 시험 ─ 합격 + AI 공개 수용 ──→ Claude 단독 또는 하이브리드 재검토 (§4 조건)
          └ 불합격 또는 공개 거부 ─→ Minifantasy 1팩 확인 ─ 통과 → 권장안 (번들 구매)
                                                  └ 실패 → 예비안 (Ninja Adventure 하이브리드)
```
