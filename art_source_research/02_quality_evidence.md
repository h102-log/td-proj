# 02. 품질 실증 — LLM이 코드로 그린 아트의 실제 사례

질문 2에 답한다. LLM(가능하면 Claude)이 코드로 만든 픽셀아트·SVG의 실제 사례와 평가는 어떤가. 잘 되는 것과 안 되는 것의 경계는 어디인가. 이렇게 만든 아트로 출시한 게임이 있는가.

확인 날짜는 모두 2026-10-11이다. 표기법은 [README](README.md#표기와-신뢰도)에 있다.

## 요약

- 사례는 대부분 개발자 본인의 소감이다. 픽셀아티스트가 직접 평가한 글은 찾지 못했다.
- 공통 경계: 규칙으로 정의되는 자산(타일, 9-slice UI, 이펙트, 기호 아이콘, 팔레트 변종)은 잘 된다. 인간형 실루엣, 1픽셀 이하 세부, 자연스러운 동작, 복잡한 구도는 약하다 [Q-22].
- 한 개발자의 결론: "a high, cheap floor, not a high ceiling" [Q-13].
- LLM이 쓴 코드로 그린 아트로 Steam에 출시했다고 확인되는 게임은 찾지 못했다 [Q-17] [X-24] (보충 조사, 별도 검증 없음).

### 벤치마크

- LLM 픽셀아트 표준 리더보드는 없다 [Q-21].
- Pixel Art Bench(24×24 격자 JSON, GPT-5.4 심판)는 공개 결과가 없다 [Q-21] [T-25].
- AM-Bench(오픈 가중치 모델 8개, Claude 미포함): 명세된 도형을 코드로 옮기는 건 모든 모델이 잘한다. 열린 구도 배치는 편차가 크다. SVG로 출력하면 배치 점수가 오른다 [Q-21].

이 프로젝트에 대입하면(추론):

- Claude 단독으로 충분할 가능성이 높은 것: 들판 타일, UI, 이펙트, 적 팔레트 변종.
- 가장 위험한 것: 인간형 유닛 4종(영웅, 용병 2, 공병)과 그 공격·사망 애니메이션.
- 그래서 유닛을 에셋팩으로 채우는 쪽이 품질 위험을 가장 많이 줄인다. 비교는 [07](07_decision.md)에 있다.

## 3. 렌더→검수 루프에 대한 사례 근거

- 루프는 구조·팔레트·배치 결함을 찾아 품질을 올린다. 하지만 사람 눈을 대신하지 못한다 [Q-23].
- 루프가 품질을 얼마나 올리는지 정량 데이터는 찾지 못했다 [Q-23]. 플롯·SVG 쪽 근거는 [01 §3](01_techniques.md#3-렌더검토-반복-루프-효과와-한계)에 있다.
- 운영 제안: 숫자 검사(팔레트 집계, 프레임 간 차이, 타일링 미리보기)를 먼저 돌린다. 이미지는 12~16배 확대와 격자를 붙인 접촉 시트로 가끔만 보여 준다. 사람이 반드시 최종 확인한다 [Q-23].
- 아트 생성에 effort 'max'를 쓰면 사용량만 소모할 위험이 있다 [Q-10].

## 4. 출시 게임이 있는가

- LLM이 쓴 코드로 그린 아트로 Steam에 출시했다고 확인되는 게임은 찾지 못했다 [Q-17].
  - CODEX MORTIS(2026-03-26 Steam 앞서 해보기)는 모든 스프라이트를 AI로 만들었다고 하지만 도구를 밝히지 않았다 [Q-17].
  - Void Balls의 스프라이트는 이미지 생성 모델(Flux, Recraft) 결과물이다 [Q-17].
  - Catvivors(Claude Code와 Codex로 제작, 2026-03-13 앞서 해보기, $4.99)의 공개 문구는 "This game code was optimized with Claude Code (AI model). Trailer for the game was partly generated with AI (initial 7 seconds)."다. 2026-10-11 현재 리뷰 0개다. 아트를 코드로 만든 사례는 아니고, 리뷰 부진이 공개 때문인지는 판단할 수 없다 [X-23] (보충 조사, 별도 검증 없음).
- itch.io에는 잼 출품작 Chargo가 있다 [Q-16]. COMPASSO는 GitHub 저장소만 확인했다 [Q-17].
- "이미지 모델 미사용, AI가 쓴 코드로 그림"이라고 공개한 Steam 픽셀 게임 문안과 그 리뷰 반응은 찾지 못했다 [X-24] (보충 조사, 별도 검증 없음).
- 함의(추론): 이 방식으로 출시하면 참고할 선례가 없다. 품질 판정은 외부 평가 대신 [08 반나절 시험](08_half_day_trial.md)의 기준에 기대야 한다.
