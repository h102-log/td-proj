# Mindustry UI 코드 근거 (Anuken/Mindustry HEAD 84fd6bf, 스파스 체크아웃 /home/user/anuken/mindustry)
Mindustry는 스팀에서 파는 도트 TD/공장 게임이다. 아래 경로:줄은 그 저장소 기준. 메인 세션이 280·38·313-321·413-415·294-295·603-604줄을 직접 열어 확인했다.

## 건설 메뉴
- M1. 건설 메뉴는 화면 오른쪽 아래에 붙은 틀 하나다. HUD가 보일 때만 보인다. PlacementFragment.java:280 (`full.bottom().right()`)
- M2. 틀은 위에서 아래로: 정보 패널 → 4단위 회색 구분선 → 블록 격자+범주 표(명령 모드면 유닛 명령 표). PlacementFragment.java:347, :438, :440, :444-460
- M3. 블록 격자는 4열(`rowWidth = 4`), 버튼 46×46 단위, 아이콘 32단위. 4개가 안 되는 줄은 빈 칸으로 채워 폭을 고정한다. PlacementFragment.java:38, :296, :310-311, :332-336
- M4. 격자는 높이 194단위 스크롤 창(약 4줄, 16개)이고 범주마다 스크롤 위치를 기억한다. :178, :679, :687-693
- M5. 범주는 격자 오른쪽의 2열 아이콘 토글 버튼(50×50, 글자·툴팁 없음). :695-737
- M6. 열린 블록이 없는 범주도 자리를 지키되 빈 검은 칸으로 끝에 둔다. :709-712, :720-722
- M7. 블록을 누르면 고르고 다시 누르면 푼다. 범주를 바꾸면 그 범주에서 마지막에 쓴 블록으로 간다. :300-309, :730-736
- M8. 숫자 키 조합: 첫 번째로 범주 N, 400ms 안에 두 번째로 그 범주의 블록 N. :60-75, :186-238
- M9. 방향키로 격자 이동, 이전/다음 범주 키, 스포이트(가운데 클릭), 블록 정보 키. :188-209, :240-272
- M10. 격자 버튼에는 단축키 표기가 없다. 단축키는 정보 패널의 이름 아래 회색 줄(«단축키: [3,1]»)에만 나온다. :372-387, bundle_ko.properties:1553

## 못 쓰는 블록
- M11. 잠긴 블록(연구 안 됨·환경 안 맞음)은 격자에서 **숨긴다**(회색·자물쇠로 그리지 않음). :294-295, :771-782
- M12. 재료가 모자란 블록은 버튼 전체를 회색(Color.gray)으로 곱해 칠하고, 가능하면 흰색. 매 프레임 다시 잰다. :313-316 («color unplacable things gray»)
- M13. 아예 놓을 수 없는 블록(금지 등)은 더 어두운 Color.darkGray, 범주 끝으로. :319-321, :772
- M14. 고른 블록은 틴트가 아니라 테두리(buttonSelect)로 표시. Styles.java:68-69, :283-286
- M15. 재료 줄은 «가진 것/필요한 것», 가진 수가 필요의 절반 미만이면 [scarlet], 필요 미만이면 [accent](노랑), 충분하면 흰색. :402-419(규칙 :413)
- M16. 막히는 이유(건설 불가 유닛, 환경, 금지, 개수 상한)는 빨간 ✕ 아이콘 + 이유 한 줄로 정보 패널에. :423-431, :753-761

## 보고자 추론(코드가 아님)
640×360에서는 Mindustry의 숫자를 그대로 쓰면 너무 크다(블록 창 194단위만으로 화면 높이의 54%). 구조만 가져온다: 오른쪽 아래 4열 격자 + 좁은 범주 줄, 그 위 고정 정보 패널(지연 없음), 단축키는 패널에, 잠긴 것은 숨기고 못 사는 것은 회색, «가진/필요» 숫자 색 3단계. 웨이브 위젯은 왼쪽 위, 필드가 비면 켜지는 건너뛰기. Mindustry에는 코어 체력 막대가 없으니 우리는 작은 막대 + 깜박이는 «공격받음» 띠 + 화면 가장자리 표시를 더한다. 토스트는 3.5초 간격. 힌트는 한 번에 하나, 끝나면 저장, 건너뛰기.
